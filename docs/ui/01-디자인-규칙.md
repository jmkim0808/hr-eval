# 1. 디자인 규칙 — 인사평가 시스템

> UI 디자인 워크숍(2026-10-01) 결과. 값의 원본은 `docs/ui/tokens.css` 하나다. 이 문서와 값이 다르면 **tokens.css가 맞다.**
> 화면을 만들 때는 이 문서의 값을 직접 적지 말고 **이름표(토큰)** 를 부른다. 예: `var(--color-button-primary-background)`

## 1. 전체 인상 — 차분하고 격식 있는 업무 도구

- 흰 상자와 회색 바탕, 화면 맨 위 **굵은 검은 머리줄(2px)**, 오른쪽 위 **"대외비 · 열람자 ○○○" 표시**를 모든 화면에 둔다.
- 장식·그림·하이라이트 색은 쓰지 않는다.
- **이유**: 극대외비 평가라 서류처럼 단정해야 한다. 다만 직각과 굵은 선만으로는 딱딱해서 A의 둥근 모서리와 옅은 바탕을 더했다.

## 2. 화면 밀도 — 보통

| 이름표 | 값 |
|---|---|
| `--size-row` (표·목록 한 줄) | 40px |
| `--font-size-body` (본문) | 14px |
| `--size-control-medium` (버튼·입력칸 높이) | 36px |

- **이유**: 관리자·직원·대표이사가 같은 규칙을 쓰는 가운데 자리다. 최종평가에서 등급 경계선의 위아래 사람이 한 화면에 함께 보인다(약 11명).

| 이름표 | 값 | 흰 글자 대비 |
|---|---|---|
| `--color-button-primary-background` | #3B4A8C | 8.3:1 |

- 쓰는 곳: 주 버튼, 선택된 메뉴 밑줄, 지금 단계, 선택된 줄·그룹, 링크, 쓰는 중인 입력칸 테두리. **이 밖에는 쓰지 않는다.**
- **이유**: 파워넷 디자인 가이드의 **인사 분야 색(Indigo)** 이라 근거가 분명하다. 하이라이트 색(시안·골드·라임)을 얹어 봤지만 산만해서, 단색이 더 단정하다고 판단했다.

## 5. 의미를 가진 색

### 5-1. 상태 색 (차분한 톤) — 항상 아이콘 + 글자와 함께

| 상태 | 글자 이름표 / 값 | 바탕 이름표 / 값 | 대비 | 아이콘 |
|---|---|---|---|---|
| 잘 됐을 때 | `--color-status-success-text` #3F6B4F | `--color-status-success-background` #E7EFEA | 5.2:1 | circle-check |
| 주의할 때 | `--color-status-warning-text` #8A5A12 | `--color-status-warning-background` #F6EEDD | 5.1:1 | triangle-alert |
| 잘못됐을 때 | `--color-status-danger-text` #9B2C2C | `--color-status-danger-background` #F6E5E5 | 6.2:1 | circle-x |
| 진행 중일 때 | `--color-status-progress-text` #3E6587 | `--color-status-progress-background` #E5EDF4 | 5.2:1 | loader-circle (돌아감) |
| 중립 (잠김·대기) | `--color-status-neutral-text` #5A6170 | `--color-status-neutral-background` #EEF0F4 | 5.5:1 | lock / clock |

- **이유**: 인디고와 차가운 회색의 단정함을 깨지 않도록 한 톤 눌렀다. 색이 차분한 대신 아이콘과 글자로 상태를 구분한다.
- 처음 안에서는 노랑 글자 3.5:1, 빨강 글자 4.0:1로 기준에 미달해서, 글자색을 한 단계 진하게 보정했다.

### 5-2. 등급 변화 표시 — 최종평가·등급 결과 화면 전용

| 뜻 | 글자 / 바탕 / 테두리 | 대비 | 표시 예 |
|---|---|---|---|
| 긍정 (상향) | `--color-grade-up-*` #1E5AA8 / #E3EDFA / #9DBBE6 | 5.8:1 | ↑ 조정 · 상향 |
| 부정 (하향) | `--color-grade-down-*` #B42318 / #FDE8E6 / #F1A9A1 | 5.6:1 | ↓ 밀려남 · 하향 |
| 중립 (규칙 처리) | `--color-grade-rule-*` #6B4E00 / #FFF3C4 / #E9C46A | 7.0:1 | = 동점 — 근속으로 하향 |

- **이유**: 회색 표시로는 조정·밀려남이 눈에 띄지 않았다. 등급 변화는 가장 민감한 정보라 일반 상태 색과 섞지 않고 별도 색으로 둔다.
- 이 표시는 **관리자와 대표이사만** 본다. 직원 평가결과에는 등급조정 여부가 드러나지 않는다.

### 5-3. 대외비 표시

- `--color-confidential-text` / `--color-confidential-border`: #7F1D1D (흰 바탕 10.0:1)
- 오른쪽 위 "대외비 · 열람자" 표시에만 쓴다.

## 6. 글자

| 항목 | 값 |
|---|---|
| 글꼴 | **Noto Sans KR** (`--font-family-base`). 웹: Google Fonts (`tokens.css`에서 불러옴). 대체: Apple SD Gothic Neo → Malgun Gothic → sans-serif |
| 굵기 | 3가지만: 400 보통(본문), 500 중간(작은 표시·표 머리·입력칸 이름표), 700 굵게(제목·버튼) |
| 숫자 | 점수·순위·인원 칸은 숫자 폭을 맞춘다 (`.t-num`) |

| 단계 | 이름표 | 크기 | 줄간격 | 굵기 | 쓰는 곳 |
|---|---|---|---|---|---|
| 화면 제목 | `--font-size-page-title` | 22 | 1.4 | 700 | 화면마다 하나. 숫자 상자의 큰 숫자 |
| 구역 제목 | `--font-size-section-title` | 18 | 1.45 | 700 | "역량 평가", "업적 평가" |
| 소제목 | `--font-size-subsection-title` | 16 | 1.5 | 700 | "2026년 개인역할 및 업적", 빈 화면 제목, [제출] 큰 버튼 |
| 본문 | `--font-size-body` | 14 | 1.6 | 400 | 본문·표·버튼·입력칸 |
| 보조 설명 | `--font-size-caption` | 13 | 1.6 | 400 | 화면 제목 아래 설명, 입력칸 이름표(500) |
| 작은 표시 | `--font-size-label-small` | 12 | 1.5 | 500 | 상태 표시, 입력칸 도움말 |

- 12px보다 작은 글자는 쓰지 않는다.
- **이유**: 글꼴은 어느 화면에서도 튀지 않는 표준 글꼴로 골랐다. 크기는 평가지 작성 화면처럼 제목이 두 겹으로 들어가는 곳 때문에 소제목 단계가 필요했다.
- 한글이 답답하지 않도록 본문 줄간격을 1.6으로 두었다. 영문 기준(1.4~1.5)보다 넉넉하다.
- 📌 파워넷 디자인 가이드의 지정 글꼴은 Pretendard다. 이 서비스는 사용자 선택에 따라 **Noto Sans KR**을 쓴다.

## 8. 간격 — 4 단위

| 이름표 | 값 | 대표 쓰임 |
|---|---|---|
| `--space-1` | 4 | 아이콘과 글자 사이(작은 표시), 이름표와 입력칸 사이 |
| `--space-2` | 8 | 버튼끼리, 아이콘과 글자 사이(버튼) |
| `--space-3` | 12 | 상자 머리줄 위아래, 입력칸 안쪽 좌우 |
| `--space-4` | 16 | 상자끼리, 상자 안쪽, 표 칸 좌우 |
| `--space-6` | 24 | 화면 위아래 여백, 큰 버튼 좌우 |
| `--space-8` | 32 | 화면 좌우 여백 |
| `--space-12` | 48 | 빈 화면 안내 위아래, 인증 화면 위 |

- 이 7개 말고는 간격 값을 쓰지 않는다.
- **이유**: 보통 밀도와 짝이 맞고, 4 단위라 작은 간격까지 같은 규칙으로 맞출 수 있다.

## 9. 부품

### 9-1. 버튼 — 4종류 (회색 테두리형)

| 종류 | 평소 | 마우스 올렸을 때 | 눌렀을 때 | 못 누를 때 |

| **보조 버튼** | 흰 바탕 + 테두리 #858C99 + 글자 #1B1F2A | 바탕 #F4F5F8, 테두리 #5A6170 | 바탕 #E9ECF1 | 위와 같음 |
| **위험 버튼** | 흰 바탕 + 빨간 테두리·글자 #9B2C2C | 바탕 #F6E5E5 | 바탕 #EFD3D3, 글자·테두리 #7E2222 | 위와 같음 |
| **글자 버튼** | 인디고 글자 + 밑줄 | 바탕 #F0F2FA | 바탕 #E1E5F4 | 회색 글자, 밑줄 없음 |

- **키보드로 골랐을 때**: 인디고 2px 바깥 테두리, 2px 띄움 (`--focus-ring-*`)
- **크기**: 작게 28(표 안), 보통 36(기본), 크게 44(화면의 마지막 버튼 — [제출] 등)
- **주 버튼은 한 화면(확인 창 포함)에 하나만** 둔다.
- 버튼 글자는 700 굵게, 아이콘은 글자 앞에 둔다. "다음/넘기기"처럼 앞으로 가는 버튼은 화살표를 글자 뒤에 둔다.
- **이유**: 주 버튼 하나만 확실히 튀어야 한다. 확정 취소처럼 자주 누르면 안 되는 버튼은 빨강으로 채우지 않고 테두리만 둔다.

- **진행 단계 줄**: 7칸. 지금 단계는 연한 인디고 바탕 + 아래 3px 인디고, 끝난 단계는 ✔ 아이콘
- **그룹 고르기**: 버튼 모양의 칸. 고른 칸은 인디고 테두리 + 연한 인디고 바탕 + 굵게
- **확인 창**: 폭 480, 뒤 덮개 rgba(27,31,42,.45), 그림자 `--shadow-overlay`, 위 제목 + 닫기(✕) / 아래 버튼(오른쪽 정렬)
- **비어 있을 때**: 가운데 정렬 아이콘 20 + 소제목 + 설명 + (있으면) 주 버튼 하나
- **기다릴 때**: 진행 막대 8px(진행 중 색) + "85 / 120" 숫자, 또는 돌아가는 loader-circle 아이콘. 임시저장은 "✔ 저장됨 10:42"

## 10. 아이콘 — Lucide만

| 항목 | 규칙 |
|---|---|
| 세트 | **Lucide만** 쓴다. 다른 세트를 섞지 않는다. 없는 아이콘은 Lucide 안에서 대체한다 |
| 선 굵기 | 2 (Lucide 기본, `--icon-stroke-width`) |
| 크기 | 14 (작은 상태 표시 안) / 16 (버튼·표·입력칸) / 20 (알림 띠·빈 화면·화살표) |
| 색 | **옆 글자와 같은 색**(currentColor). 아이콘에만 따로 색을 주지 않는다 |
| 아이콘만 있는 버튼 | **허용하지 않는다.** 예외는 확인 창 닫기(✕) 하나뿐이며, 이때도 "닫기" 이름(title·읽기 이름)을 단다 |

- **이유**: 1년에 한 번 쓰는 직원이 그림만 보고 뜻을 짐작하기 어렵다. 굵기 2는 굵은 버튼 글자와 무게가 맞고, Lucide 기본값이라 따로 설정할 것이 없다.
