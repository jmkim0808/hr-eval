UX 단계 흑백 와이어프레임과 같은 순서로, 확정한 디자인 규칙(tokens.css · components.css)을 입혔다. 화면마다 잘 됐을 때 · 비어 있을 때 · 기다릴 때 · 잘못됐을 때를 함께 둔다. 이름·숫자는 예시다.

S00 이메일 인증

답하는 질문: "나 맞나요?" · 쓰는 사람: 모두 (직원·팀장·임원·관리자·대표이사)

[인증하기] → 역할에 맞는 첫 화면: 직원·팀장·임원 → 내 할 일 · 관리자 → 진행 현황 · 대표이사 → 등급 결과

A01 진행 현황

답하는 질문: "지금 누가 어디서 멈춰 있지?" · 쓰는 사람: 관리자

처음이면 [평가 시작 설정]을 눌러 A02 평가 시작 설정으로 간다. 진행 중에는 관리자 메뉴에서 가점 입력 · 최종평가 · 결과 발송으로 간다.

A02 평가 시작 설정

답하는 질문: "누구를, 누가, 언제까지 평가하지?" · 쓰는 사람: 관리자

[안내 이메일 발송]을 누르면 A01 진행 현황으로 돌아가 "발송 중 85 / 120"이 보인다. 이때부터 개인작성 기간이 시작된다.

S01 내 할 일

답하는 질문: "내가 지금 해야 할 게 뭐고, 언제까지지?" · 쓰는 사람: 직원·팀장·임원 (관리자 본인도)

가장 급한 할 일 한 줄을 누름 → 평가지 작성 (내 평가지) 또는 평가하기 (1차·2차·팀장 평가 묶음)

S02 평가지 작성

답하는 질문: "내 평가지에 무엇을 써야 하지?" · 쓰는 사람: 직원·팀장 (피평가자)

[제출] → 내 할 일로 돌아감. "제출 완료 — 11/7까지 고칠 수 있습니다"가 뜸

S03 평가하기

답하는 질문: "이 사람에게 몇 점을 줄까?" · 쓰는 사람: 팀장·임원 / 관리자는 보기 전용

[제출] → 목록에 "완료" · [다음 사람] → 같은 화면의 다음 피평가자 · 묶음이 끝나면 내 할 일에 "8명 중 8명 완료" · 관리자는 [닫기] → 원래 목록

A03 가점 입력

답하는 질문: "가점이 모두 제대로 들어갔나?" · 쓰는 사람: 관리자

관리자 메뉴에서 A01 진행 현황으로 돌아간다. 2차평가 기간을 넘기면 A04 최종평가에 초안이 나온다.

A04 최종평가

답하는 질문: "그룹별로 누가 어떤 등급이고, 조정하면 누가 밀리지?" · 쓰는 사람: 관리자

[확정]하면 결과 발송으로 간다. 같은 시간 대표이사 화면(E01)에는 조정이 바로 보인다.

E01 등급 결과 (대표이사)

답하는 질문: "그룹별로 누가 어떤 등급이지?" · 쓰는 사람: 대표이사 (보기만)

관리자가 [확정]하면 이 화면에 "확정됨"이 보이고, 관리자는 결과 발송으로 간다.

A05 결과 발송

답하는 질문: "결과를 내보냈고, 이 평가를 끝내도 되나?" · 쓰는 사람: 관리자

[평가 마감]을 누르면 진행 현황으로 돌아가고 "2026년 정기평가 마감 (12/15, 마감자 홍길동)"이 보인다.

A06 관리자 설정

답하는 질문: "누가 관리자지?" · 쓰는 사람: 관리자

관리자 메뉴의 [진행 현황]으로 돌아간다.
