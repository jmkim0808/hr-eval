# 6. 선택 기록 — UI 디자인 워크숍 (2026-10-01)

> 라운드마다 본 선택지, 고른 것, 고른 이유(한 문장). 나중에 "왜 이렇게 했지?"의 근거로 쓴다.

| 라운드 | 본 선택지 | 고른 것 | 고른 이유 |
|---|---|---|---|
| **0. 레퍼런스** | 실제 서비스(flex·Lattice·모두싸인·DocuSign·Culture Amp)는 작업 환경의 네트워크 정책으로 접속이 막혀 사용자 동의 아래 **시안 3개로 대체**함: A 차분한 업무 도구 / B 여유롭고 친근한 카드형 / C 공문서 같은 단정함 | **C + A의 부드러움** | 극대외비 평가라 서류처럼 단정해야 하지만, 너무 직각적이라 A의 부드러움을 살짝 섞었다 |
| **1. 전체 인상** | (0라운드 답으로 정해짐) | 차분하고 격식 있는 업무 도구 | 0라운드 선택이 곧 전체 인상이라 따로 묻지 않았다 |
| **2. 화면 밀도** | A 촘촘(줄 32, 글자 13) / B 보통(40, 14) / C 여유(52, 15) | **B 보통** | 세 종류 사람이 같은 규칙을 쓰는 가운데 자리이고, 등급 경계선의 위아래가 한 화면에 보인다 |
| **3. 기준색 (1차)** | A 파워넷 블루 #034EA2 / B 인디고 #3B4A8C / C 적갈색 #7F1D1D | 인디고가 좋지만 "너무 클래식해서 멋없다" → 하이라이트 추가 요청 | — |
| **3. 기준색 (2차)** | 인디고 + 하이라이트: A 시안 / B 골드 / C 라임 | **하이라이트 없이 인디고 단색** | 하이라이트를 얹으니 산만해서 단색이 더 단정했다 |
| **4. 바탕·회색** | A 따뜻한 회색(종이) / B 차가운 회색(인디고 기운) / C 순백 | **B 차가운 회색** | 인디고와 온도가 같아 한 덩어리로 정돈되어 보인다 |
| (중간 확인 1) | 평가지 작성 화면에 2~4번 적용 | 통과 | — |
| **5. 상태 색** | A 파워넷 가이드 계열 / B 선명하게 / C 차분하게 | **C 차분하게** | 인디고·회색의 단정함을 깨지 않고, 상태는 아이콘과 글자로 구분한다 |
| **6-1. 글꼴** | A Pretendard(파워넷 가이드 지정) / B IBM Plex Sans KR / C Noto Sans KR | **C Noto Sans KR** | 어느 화면에서도 튀지 않는 가장 표준적인 글꼴이 단정한 도구에 맞다 (가이드 지정 글꼴과 다름을 기록) |
| **6-2. 글자 크기 단계** | A 5단계 / B 6단계 / C 7단계 | **B 6단계** (굵기 400·500·700) | 평가지 작성처럼 제목이 두 겹인 화면에 소제목 단계가 필요하다 |
| (중간 확인 2) | 최종평가 화면에 적용 | **표시 항목이 눈에 안 띈다** → 긍정 파랑 / 부정 빨강 / 중립 노랑 상자 요청 | 경계선 사람이 한눈에 보여야 한다 |
| **5-2. 등급 변화 표시 범위** | (가) 등급 변화 표시에만 / (나) 모든 상태 색을 바꿈 | **(가)** | 등급 변화는 가장 민감한 정보라 다른 상태와 섞이지 않는 편이 안전하다 |
| **7. 형태** | A 2px+테두리 / B 6px+테두리 / C 10px+그림자 | **B 6px + 테두리** | 클래식에 부드러움을 살짝 더한 방향과 맞고, 출력·저화질에서도 선명하다 |
| **8. 간격** | A 좁게(8·12·24) / B 보통(8·16·32) / C 넓게(16·24·48) | **B 4 단위 보통** | 보통 밀도와 짝이 맞고 작은 간격까지 같은 규칙으로 맞출 수 있다 |
| **9-1. 버튼** | A 회색 테두리형 / B 연한 바탕형 / C 인디고 테두리형 | **A 회색 테두리형** | 주 버튼 하나만 확실히 튀고, 확정 취소처럼 자주 누르면 안 되는 버튼은 조용히 둔다 |
| **9-2. 입력칸·상자·목록 한 줄** | 정해진 규칙으로 만든 한 장을 확인 | 통과 | 새로 고를 것 없이 앞 결정의 조합이었다. 입력칸 테두리는 3:1 기준을 위해 진한 회색을 따로 둠 |
| **10. 아이콘** | Lucide 선 굵기 A 1.5 / B 2 / C 2.5 | **B 2**, 아이콘만 있는 버튼 금지(닫기 ✕ 예외) | 굵은 버튼 글자와 무게가 맞고 기본값이라 설정이 필요 없다. 1년에 한 번 쓰는 직원에게 그림만 있는 버튼은 뜻이 안 읽힌다 |
