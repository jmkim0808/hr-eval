# 4. 유저스토리와 화면 연결표

> 기준: `docs/domain/04-유저스토리-초안.md` (US-01 ~ US-17)

| 유저스토리 | 해결되는 화면 | 화면에서 어떻게 |
|---|---|---|
| **US-01** 평가 대상자 확정 | A02 평가 시작 설정 | 직원 명단 템플릿 올리기 → 미리보기에서 6월 말 이후 입사자 자동 제외, 그룹·평가지 종류 자동 지정 → 반영하기 |
| **US-02** 평가자 지정 | A02 평가 시작 설정 | 대상자 표의 1차·2차 평가자 칸. 부서이동자는 평가 진행 시점 부서 팀장·임원으로 고침 |
| **US-03** 일정 설정과 전사 안내 | A02 평가 시작 설정 | 개인작성·1차평가·2차평가 기간, 가점 인정 기준일 입력 → [안내 이메일 발송] |
| **US-04** 평가지 작성·제출 | S01 내 할 일 → S02 평가지 작성 | 본인평가·업적 기술, 임시저장, [제출], 기간 안 수정 |
| **US-05** 1차 평가 | S01 내 할 일 → S03 평가하기 | 팀원 묶음, 점수 입력, [제출]·[다음 사람]. 2차 점수 칸 안 보임 |
| **US-06** 2차 평가·팀장 평가 | S01 내 할 일 → S03 평가하기 | 1차 점수와 나란히 입력. 1차평가 기간에는 보기만 |
| **US-07** 제출 현황판 | A01 진행 현황 | 단계 줄, 미제출자 목록, 평가하기 보기 전용 열기 |
| **US-08** 미제출자 독촉 | A01 진행 현황 | 미제출자 골라 [독촉 이메일] |
| **US-09** 가점 입력·일괄 반영 | A03 가점 입력 | 템플릿 내려받기·올리기 → 미리보기 → 반영하기, 줄 눌러 한 사람씩 입력 |
| **US-10** 평가 점수 자동 계산 | A04 최종평가 (S03 보기 전용에도 표시) | 최종점수 칸에 자동 계산값, 펼치면 1차·2차·가점 |
| **US-11** 그룹별 상대평가 등급 초안 | A04 최종평가 | 그룹 고르기, 초안 등급, 반올림 인원 요약, "동점 — 근속으로 하향" |
| **US-12** 대표이사 결과 열람 | E01 등급 결과 | 보기만, 조정은 실시간 반영 |
| **US-13** 등급조정 입력과 연쇄 변동 표시 | A04 최종평가 (E01에 즉시 반영) | 등급 칸 → "이렇게 바뀝니다" 미리보기 → [적용], 조정/밀려남 표시, 줄마다 [되돌리기] |
| **US-14** 평가등급 확정 | A04 최종평가 | [확정], 이메일 발송 전까지 [확정 취소] |
| **US-15** 최종결과 엑셀 내려받기 | A05 결과 발송 | [최종결과 엑셀 내려받기] |
| **US-16** 평가결과 이메일 발송 | A05 결과 발송 → S04 내 평가결과 | 알림 메일(링크만) 발송, 실패자 [다시 보내기] → 직원은 이메일 인증 후 S04에서 결과 확인 (2026-10-01 기술 결정으로 S04 추가) |
| **US-17** 관리자 추가 설정 | A06 관리자 설정 | [관리자 추가], [해제] |

**연결되지 않은 유저스토리: 없음.**

## 4-1. UX 워크숍에서 새로 생긴 할 일 (유저스토리 추가 후보)

아래는 워크숍에서 정해졌지만 도메인 문서의 유저스토리에는 아직 없는 할 일이다. 다음 정리 때 유저스토리로 올릴 후보다.

| 후보 | 화면 | 내용 |
|---|---|---|
| UX-A 이메일 인증 | S00 | 모든 사람이 이메일 인증번호로 들어온다 (극대외비) |
| UX-B 다음 단계로 넘기기 | A01 | 관리자가 단계를 넘기면 앞 단계가 잠긴다. 미제출자가 있으면 확인 후 빈칸인 채로 잠긴다 |
| UX-C 기간 안 자유 수정·임시저장 | S02, S03 | 기간 안에서는 제출 후에도 고칠 수 있고, 쓰는 내용은 저절로 저장된다 |
| UX-D 직원 명단 템플릿 | A02 | 매년 직원 명단 엑셀을 새로 올린다 (US-01의 "불러오기"를 구체화) |
| UX-E 확정 취소 | A04 | 평가결과 이메일 발송 전까지, 사유를 남기고 다른 관리자에게 알린다. 가점 입력은 다시 열리지 않는다 (US-14 보완) |
| UX-F 평가 마감 | A05 | 연봉조정까지 확인한 관리자가 누르면 그해 평가가 보기 전용 기록이 된다 |
