# 3. 화면별 상태 정의

> 화면마다 네 가지 상태에서 무엇이 보이는지 정리했다: 비어 있을 때, 기다릴 때, 잘 됐을 때, 잘못됐을 때.
> 표기: **(가정)** = 워크숍에서 정하지 않고 설계자가 채운 것.

| 화면 | 비어 있을 때 | 기다릴 때 | 잘 됐을 때 | 잘못됐을 때 |
|---|---|---|---|---|
| **S00 이메일 인증** | 이메일과 인증번호 칸 | "인증번호를 보냈습니다. 메일함을 확인하세요." + [다시 보내기] (1분 뒤 활성) | 역할에 맞는 첫 화면으로 이동 | "번호가 맞지 않습니다" / "시간이 지났습니다" + [다시 보내기]. 등록되지 않은 이메일이면 "평가 대상이 아닙니다. 관리자에게 문의하세요." (가정) |
| **S01 내 할 일** | "지금 할 일이 없습니다" + 다음 일정 (예: "1차평가 기간 11/10 ~ 11/17") | 없음 | 묶음마다 "8명 중 8명 완료", 내 평가지 "제출 완료 — 11/7까지 고칠 수 있습니다" | 기간이 지난 묶음에 "**기한 지남**" (계속 쓸 수 있음). 잠긴 것은 "제출 완료 (잠김)" 또는 "미제출 (잠김)" |
| **S02 평가지 작성** | 빈 본인평가·업적 기술 칸 + 칸마다 작성 안내 | 없음 (임시저장은 "저장됨 10:42"로만 표시) | 제출 → 내 할 일에 "제출 완료" | 빈 칸이 있는데 [제출] → 빈 칸 위치를 알려 주고 그 칸으로 이동 (가정). 관리자가 넘긴 뒤 → 보기 전용 + "개인작성 기간이 끝나 고칠 수 없습니다" |
| **S03 평가하기** | 평가할 사람이 없으면 "이 기간에 평가할 사람이 없습니다" | 없음 | 제출 → 목록에 "완료" 표시, [다음 사람] | 점수 빈칸이 있는데 [제출] → 빈 칸 표시 (가정). 1차평가 기간 중 임원 → "2차평가 기간에 입력할 수 있습니다" (보기만). 피평가자가 미제출로 잠긴 경우 → "본인 작성 없음" 표시 후 점수만 입력. 단계가 넘어간 뒤 → 보기 전용 |
| **A01 진행 현황** | "아직 시작한 평가가 없습니다" + **[평가 시작 설정]** | 이메일 발송 중이면 "발송 중 85 / 120" (화면을 떠나도 계속) | 단계 줄에 ✔, "미제출 0명". 마감 후 "2026년 정기평가 마감 (12/15, 마감자 ○○○)" | 미제출자 있는 채로 넘기기 → 명단 확인 창. 이메일 실패 → 실패 명단 + [다시 보내기] |
| **A02 평가 시작 설정** | [템플릿 내려받기] · [템플릿 올리기] + "직원 명단을 먼저 올려 주세요" | 올린 뒤 몇 초 "확인 중" | 미리보기 → [반영하기] → 대상자 표 채워짐. 발송 후 진행 현황으로 | 미리보기에 "제외 3명 (7월 이후 입사)", "확인 필요 2명 (이메일 빈칸 등)". 확인 필요가 남으면 [반영하기]가 눌리지 않음. 평가자가 비어 있는 사람이 있으면 [안내 이메일 발송]이 눌리지 않음 |
| **A03 가점 입력** | "아직 가점이 없습니다" + [템플릿 내려받기] · [템플릿 올리기] | 올린 뒤 몇 초 "확인 중" | 미리보기 → [반영하기] → 가점 표 채워짐, "가점 반영 120 / 120" | "이름이 맞지 않는 2명" 따로 표시 → 템플릿을 고쳐 다시 올리거나 줄을 눌러 직접 입력. 팀원 줄의 다면평가 칸은 입력할 수 없음. 평가등급 확정 뒤에는 보기 전용 + "평가등급이 확정되어 가점을 더 이상 인정하지 않습니다" |
| **A04 최종평가** | "2차평가가 끝나면 초안이 나옵니다 (남은 인원 12명)" | 없음 | 초안 → 조정 → [확정] → "확정됨 (11/28, 확정자 ○○○)" | 동점자 줄에 "동점 — 근속으로 하향". 가점 미반영자가 있으면 [확정] 전에 "가점 미반영 2명" 경고 (가정). 확정 뒤 잘못을 발견하면 [확정 취소] (이메일 발송 전까지, 사유 입력, 다른 관리자 알림, 가점 입력은 다시 열리지 않음) |
| **A05 결과 발송** | 확정 전: "평가등급을 확정하면 보낼 수 있습니다" (발송 버튼 비활성) | "발송 중 85 / 120" (화면을 떠나도 계속) | "발송 완료 120명" → [평가 마감] → 마감 표시 | "실패 2명" + 명단 + [다시 보내기]. 실패자가 남아 있어도 **마감할 수 있음** (실패자는 수기 전달) |
| **A06 관리자 설정** | 없음 (처음부터 관리자 2명) | 없음 | 추가 → 목록에 나타남. 추가된 사람에게 안내 이메일 (가정) | 마지막 1명은 해제할 수 없음 (가정) |
| **E01 등급 결과** | "아직 보고할 결과가 없습니다" | 없음 (조정은 즉시 반영) | "확정됨" 표시 | 없음 (보기만) |

## 3-1. 화면 공통 신호

| 신호 | 뜻 |
|---|---|
| **기한 지남** | 기간이 지났지만 아직 쓸 수 있음 |
| **잠김** | 관리자가 다음 단계로 넘겨 고칠 수 없음 |
| **작성 중** | 임시저장된 내용이 있음 |
| **제출 완료** | 제출했고, 기간 안이면 고칠 수 있음 |
| **조정 / 밀려남** | 등급조정으로 등급이 바뀐 사람 / 그 때문에 한 칸 움직인 사람 |
| **확정됨** | 평가등급 확정. 이메일 발송 전까지만 확정 취소 가능 |
| **마감** | 그해 평가 끝. 보기 전용 기록 |
