## 2-2. 화면 정의

### S00. 이메일 인증
- **답하는 질문**: "나 맞나요?"
- **화면에 있는 것**
  - 이메일 주소 (링크로 들어온 경우 미리 채워짐)
  - 인증번호 넣는 칸
  - "인증번호를 보냈습니다. 메일함을 확인하세요." 안내
  - [다시 보내기] (1분 뒤부터 누를 수 있음)
- **가장 크게 보일 행동**: **[인증하기]**
- **다음 화면**: 관리자 → 진행 현황 / 직원·팀장·임원 → 내 할 일 / 대표이사 → 등급 결과 / 인증이 끊겨서 온 경우 → 하던 화면 (가정)

### S01. 내 할 일
- **답하는 질문**: "내가 지금 해야 할 게 뭐고, 언제까지지?"
- **화면에 있는 것**
  - 맨 위: 지금 단계와 기간 (예: "1차평가 기간 11/10 ~ 11/17, D-3")
  - **가장 마감이 급한 할 일 한 줄** (크게)
  - 할 일 묶음
    - 내 평가지 작성: 상태 "작성 전 / 작성 중 / 제출 완료 — 11/7까지 고칠 수 있습니다 / 제출 완료 (잠김)"
    - 1차 평가 (팀장): "팀원 8명 중 5명 남음"
    - 2차 평가 (임원): "2차 평가 가능 3명 / 1차 대기 중 6명"
    - 팀장 평가 (임원): "4명 중 4명 남음"
  - 기간이 지났으면 묶음마다 "**기한 지남**" 표시
  - 다 끝난 묶음은 "8명 중 8명 완료"로 표시하고 아래로 내림
- **가장 크게 보일 행동**: **가장 마감이 급한 할 일 한 줄** (누르면 바로 들어감)
- **다음 화면**: 평가지 작성 / 평가하기

### S02. 평가지 작성
- **답하는 질문**: "내 평가지에 무엇을 써야 하지?"
- **화면에 있는 것**
  - 머리: 2026년 정기평가 · 팀원용(또는 팀장용) 인사평가지 · 부서 · 성명 · 개인작성 기간
  - 임시저장 상태: "저장됨 10:42"
  - 역량 평가 10개 항목: 역량명, 세부 지표, **본인평가** 1~10 (팀장용은 팀장역량 포함)
  - 업적 평가: "2026년 개인역할 및 업적", "2027년 개선 및 발전" 두 칸
  - 안내: "가점은 관리자가 입력합니다"
  - 평가자 점수 칸은 **보이지 않음**
- **가장 크게 보일 행동**: **[제출]**
- **다음 화면**: 제출 → 내 할 일
- **잠김 상태**: 관리자가 넘긴 뒤에는 같은 화면이 보기 전용이 되고, [제출]은 사라짐

### S03. 평가하기
- **답하는 질문**: "이 사람에게 몇 점을 줄까?"
- **화면에 있는 것**
  - 피평가자 목록 (같은 묶음): 이름, 상태 (미평가 / 작성 중 / 완료)
  - 선택한 사람의 평가지
    - 피평가자가 쓴 본인평가와 업적 기술 (읽기만)
    - 역량 10개 항목 점수 칸 1~10, 업적 점수 칸 1~10
  - **임원**: 1차 팀장 점수가 옆 칸에 함께 보임
  - **팀장**: 2차 임원 점수 칸이 **보이지 않음**
  - 1차평가 기간 중 임원이 들어온 경우: "1차평가 진행 중 — 2차평가 기간에 입력할 수 있습니다" (보기만)
  - **관리자 보기 전용**: 모든 점수 칸(본인평가·1차·2차·가점·최종점수)이 보이고, 입력은 안 됨
- **가장 크게 보일 행동**: **[제출]** + **[다음 사람]**
- **다음 화면**: 다음 사람 (같은 화면) / 묶음이 끝나면 내 할 일 / 관리자는 닫으면 원래 목록

### A01. 진행 현황 (관리자 첫 화면)
- **답하는 질문**: "지금 누가 어디서 멈춰 있지?"
- **화면에 있는 것**
  - 위쪽 관리자 메뉴 (가정)
  - **단계 줄**: 개인작성 → 1차평가 → 2차평가 → 가점 → 최종평가 → 확정 → 결과 발송. 끝난 단계에 ✔, 지금 단계와 남은 기간 표시
  - 지금 단계의 숫자: "제출 112 / 미제출 8"
  - **미제출자 목록**: 이름, 부서, 역할 (직원/팀장/임원), 상태 (작성 전/작성 중), 마지막 독촉일
  - 가점 반영 상태: "가점 반영 118 / 120"
  - 최근 이메일 발송 결과 (발송 완료/실패)
  - 평가 마감 후: "2026년 정기평가 마감 (12/15, 마감자 ○○○)"
- **가장 크게 보일 행동**: **[다음 단계로 넘기기]** (둘째 자리: [독촉 이메일])
- **다음 화면**: 평가 시작 설정 / 가점 입력 / 최종평가 / 결과 발송 / 관리자 설정 / 평가하기(보기 전용)
- **넘기기 확인 창**: "미제출 3명 (김○○, 이○○, 박○○). 넘기면 이 사람들은 빈칸인 채로 잠깁니다. 그래도 넘길까요?" [넘기기] [취소]

### A02. 평가 시작 설정
- **답하는 질문**: "누구를, 누가, 언제까지 평가하지?"
- **화면에 있는 것**
  - ① 직원 명단: [템플릿 내려받기] [템플릿 올리기] → 미리보기 ("반영 115 · 제외 3 · 확인 필요 2") → [반영하기]
  - ② 대상자 표: 이름, 부서, 직급, 입사일, **그룹**, **평가지 종류**(팀원용/팀장용), **1차 평가자**, **2차 평가자** — 평가자 칸은 바꿀 수 있음 (부서이동자 처리)
  - ③ 기간: 개인작성 기간, 1차평가 기간, 2차평가 기간, 가점 인정 기준일
  - ④ 안내 이메일 미리보기
- **가장 크게 보일 행동**: **[안내 이메일 발송]** (명단과 기간이 모두 채워져야 눌림)
- **다음 화면**: 발송하면 진행 현황

### A03. 가점 입력
- **답하는 질문**: "가점이 모두 제대로 들어갔나?"
- **화면에 있는 것**
  - [템플릿 내려받기]
  - 미리보기: "120명 중 118명 일치 · 이름이 맞지 않는 2명" → [반영하기]
  - 가점 표: 이름, 부서, 자격증, 포상, 직무발명보상, 교육참여도, 징계사항, 내부회계관리제도, 다면평가(팀장만), 가점 합계 — 줄을 누르면 한 사람씩 입력
  - 안내: "가점 인정 기준일 11/14"
- **가장 크게 보일 행동**: **[템플릿 올리기]**
- **다음 화면**: 진행 현황 (관리자 메뉴)

### A04. 최종평가
- **답하는 질문**: "그룹별로 누가 어떤 등급이고, 조정하면 누가 밀리지?"
- **화면에 있는 것**
  - 그룹 고르기: 1그룹 팀장 / 2그룹 부장 / 3그룹 차장 / 4그룹 과장 / 5그룹 대리이하
  - 등급별 인원 요약: "S 1 · A 4 · B 12 · C 3 · D 1" (반올림 적용)
  - 표: 순위, 이름, 부서, 최종점수 (펼치면 1차·2차·가점), 초안 등급, **조정 후 등급**, 표시 (조정 / 밀려남 / 동점 — 근속으로 하향)
  - 등급 칸 누르기 → **"이렇게 바뀝니다"** 미리보기 → [적용] / [취소]
  - 줄마다 [되돌리기]
  - 상태: 초안 / 조정 중 / 확정됨 (확정자·시각)
  - 확정 후: [확정 취소] (평가결과 이메일 발송 전까지만)
- **가장 크게 보일 행동**: **[확정]**
- **다음 화면**: 확정 → 결과 발송 / 사람 누르기 → 평가하기(보기 전용)
- **확정 취소 창**: 사유 입력 칸 + "다른 관리자에게 알림이 갑니다" + [확정 취소]

### A05. 결과 발송
- **답하는 질문**: "결과를 내보냈고, 이 평가를 끝내도 되나?"
- **화면에 있는 것**
  - [최종결과 엑셀 내려받기]
  - 평가결과 이메일 미리보기 (한 사람 예시): 1차 점수, 2차 점수, 가점, 최종점수, 평가등급, 상위 %
  - 발송 진행: "발송 중 85 / 120" → "발송 완료 118 · 실패 2" + 실패 명단 [다시 보내기]
  - [평가 마감] + 안내 "연봉조정까지 끝난 것을 확인한 뒤 누르세요"
- **가장 크게 보일 행동**: **[평가결과 이메일 발송]** (확정 전에는 눌리지 않음)
- **다음 화면**: 평가 마감 → 진행 현황 (마감 표시)
- 발송 시점은 **관리자가 버튼을 누르는 때**다. 날짜를 정해 두는 예약 발송은 두지 않는다 (가정).

### A06. 관리자 설정
- **답하는 질문**: "누가 관리자지?"
- **화면에 있는 것**
  - 관리자 목록: 이름, 이메일, 추가한 날, [해제]
  - 관리자가 1명만 남으면 해제할 수 없음 (가정)
- **가장 크게 보일 행동**: **[관리자 추가]** (이메일 입력)
- **다음 화면**: 진행 현황 (관리자 메뉴)

### E01. 등급 결과 (대표이사)
- **답하는 질문**: "그룹별로 누가 어떤 등급이지?"
- **화면에 있는 것**
  - 그룹 고르기 (크게)
  - 등급별 인원 요약
  - 표: 순위, 이름, 부서, 직급, 최종점수, 등급, 조정 표시
  - 상태: "조정 중 (실시간 반영)" / "확정됨"
  - 고치는 칸과 버튼 없음
- **가장 크게 보일 행동**: 버튼 없음. **그룹 고르기**
- **다음 화면**: 없음
