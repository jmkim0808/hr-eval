# 6. 다음 단계로 넘길 메모

> 이번 워크숍에서는 동선과 화면 구성만 정했다. 색, 글꼴, 아이콘, 간격, 버튼 모양은 다음 단계에서 정한다.

## 6-1. 대화 중 나온 색·글꼴·분위기 이야기

- 워크숍 중 색·글꼴·분위기에 대한 이야기는 **나오지 않았다.**

## 6-2. 다음 단계에서 참고할 것 (워크숍에서 나온 말 중 화면 분위기에 영향을 줄 것)

| 나온 말 | 다음 단계에서 고려할 점 |
|---|---|
| "인사평가의 **극대외비성** 성격" | 화면이 가벼워 보이지 않아야 한다. 화면 캡처·출력에 대한 경고 문구나 열람자 표시가 필요한지 검토 |
| 사내 공식 문서 | 파워넷 디자인 가이드를 적용할지 여부 (사용자 기본 설정상 파일 산출물에는 적용 대상) |
| 120명이 1년에 한 번 쓰는 서비스 | 처음 보는 사람도 설명 없이 쓸 수 있는 평범한 모양이 우선 |
| 등급(S~D)·조정/밀려남 표시 | 색만으로 구분하지 말고 글자로도 구분할 것 (흑백 와이어프레임에서 이미 글자로 표시함) |

## 6-3. 화면 설계에서 남은 확인 사항 (색과 무관)

| 항목 | 이유 |
|---|---|
| 관리자(파트장·경영지원실장) 본인도 평가 대상일 때, 관리자 화면에서 **자기 평가의 1·2차 점수와 등급**을 보게 되는 문제 | 극대외비 원칙과 충돌할 수 있음 |
| 임원의 **팀장 평가**를 1차평가 기간에 할지, 2차평가 기간에 할지 | 도메인 문서는 2차평가 단계에 함께 적혀 있으나, 팀장 평가는 "1차만"이라 1차평가 기간에 해도 됨 |
| 최종평가 초안·등급조정 뒤에 가점을 고치면 초안을 다시 계산할지, 조정 내용을 유지할지 | 확정 취소 후 가점 수정 상황과 연결 |
| 평가결과 이메일 실패자가 남아 있어도 평가 마감을 할 수 있는지 | A05 잘못됐을 때 상태 |
