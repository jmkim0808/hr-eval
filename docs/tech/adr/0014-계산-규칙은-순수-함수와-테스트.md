# ADR-0014 점수·등급 계산은 한 모듈의 순수 계산 + 테스트, 결과는 저장

- **정해야 했던 것**: 엑셀 수식 재검토를 없애는 것이 핵심 불편 해소다. 계산을 어디서, 언제 할지.
- **선택지**: ① DB 안의 계산(뷰·함수) ② 화면이 열릴 때마다 계산 ③ 서버의 계산 모듈(입력→출력만 하는 순수 함수)로 계산하고, 2차평가를 넘길 때와 가점·조정이 바뀔 때 저장
- **고른 것**: ③. `domain/grading`에 점수 공식, 반올림 인원, 근속 동점, 밀려남 연쇄, 통보용 상위 % 계산을 모으고, 도메인 문서의 예시로 테스트를 만든다. 결과는 `final_results`에 저장해 대표이사 화면·엑셀·내 평가결과가 **같은 값**을 보게 한다. 숫자는 `numeric`과 정수 계산으로 다루고 소수점 둘째 자리에서 반올림한다(실수 오차 방지).
- **포기한 것**: DB만으로 계산을 확인하는 방법. 대신 회사 DB로 옮겨도 계산이 그대로다.
- **다시 볼 때**: 평가 공식이나 비율이 바뀔 때 (양식 판 `form_version`을 올리고 테스트를 고친다).
