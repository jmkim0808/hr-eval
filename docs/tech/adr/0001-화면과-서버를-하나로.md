# ADR-0001 화면과 서버를 Next.js 프로그램 하나로

- **정해야 했던 것**: 화면과 서버를 따로 만들지, 하나로 만들지.
- **선택지**: ① Next.js 하나 (서버에서 화면을 그림 + 서버 동작) ② 화면(React)과 API 서버를 따로 ③ 노코드 도구
- **고른 것**: ① Next.js (App Router, TypeScript). 화면은 기본적으로 서버에서 그리고, 입력·저장은 서버 동작(Server Actions)으로 처리한다. 브라우저 쪽 코드는 입력칸·자동저장·진행 숫자처럼 꼭 필요한 곳에만 쓴다.
- **포기한 것**: 화면과 서버를 따로 배포하는 유연함. 120명이 연 1회 쓰는 사내 도구에는 필요 없다. 노코드는 "팀장은 2차 점수를 못 봄" 같은 칸 단위 권한을 표현하기 어려워 뺐다.
- **다시 볼 때**: 모바일 앱을 따로 만들거나, 다른 시스템(그룹웨어 등)이 이 데이터를 가져가야 할 때.
