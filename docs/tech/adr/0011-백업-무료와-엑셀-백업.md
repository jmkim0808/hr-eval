# ADR-0011 백업: Supabase 무료로 시작 + 매일 깨우기 + 마감 백업 엑셀

- **정해야 했던 것**: Supabase 무료 플랜은 7일 동안 안 쓰면 멈추고, 자동 백업이 없다. 이 서비스는 1년 중 10달을 쉰다.
- **선택지**: ① 1년 내내 무료 ② 평가 기간(약 10~12월)만 Pro(월 25달러, 매일 백업 7일치) ③ 1년 내내 Pro
- **고른 것**: ① **우선 무료** (결정권자 결정, 2026-10-01). 보완책은 세 가지다. (1) 하루 한 번 예약 실행이 DB에 가벼운 조회를 보내 멈춤을 막는다. (2) 평가 기간 중 **단계를 넘길 때와 확정할 때마다 관리자에게 "이 시점 전체 기록 엑셀" 내려받기를 안내**하고, 관리자가 사내 보안 저장소에 보관한다. (3) 평가 마감 때 그해 전체 기록 엑셀을 내려받는다. 등급조정은 지우지 않고 이력으로 남겨 되돌릴 수 있다.
- **포기한 것**: 평가 기간 중 자동 백업. 사고가 나면 마지막으로 내려받은 엑셀 시점까지만 되살릴 수 있고, 엑셀에서 다시 넣는 작업은 사람이 해야 한다.
- **다시 볼 때**: 첫 실제 평가 시작 2주 전 (그때 ②로 바꿀지 다시 묻는다) / 데이터 사고가 한 번이라도 날 때 / 회사 서버로 옮길 때 / 자동 깨우기가 Supabase 정책상 막힐 때.
