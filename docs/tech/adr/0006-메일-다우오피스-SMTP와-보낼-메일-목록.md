# ADR-0006 메일: 다우오피스 메일 계정(SMTP) + "보낼 메일 목록"을 1분마다 비우기

- **정해야 했던 것**: 인증번호·안내·독촉·결과 알림을 무엇으로, 어떻게 보낼지. 한 번에 120통.
- **선택지**: ① Resend 무료 (하루 100통 제한으로 첫날 불가) ② Resend 유료 월 20달러 ③ 회사 메일(다우오피스) SMTP
- **고른 것**: ③ (결정권자 선택). 발송 전용 계정(예: `hr-eval@회사도메인`)을 쓴다. Workers에서는 TCP 연결로 SMTP(465 또는 587 포트)를 쓰고, 회사 서버에서는 nodemailer를 쓴다. 둘 다 `MailSender` 하나의 약속 뒤에 둔다. 인증번호는 즉시 보내고, 나머지는 `email_outbox`에 쌓는다. 쌓은 직후 10통을 바로 보내고, 남은 것은 1분마다 예약 실행이 10통씩 보낸다(무료 플랜 한도 대비 — 120통이 약 12분). 실패하면 3번까지 다시 보내고, 그래도 안 되면 "실패"로 남긴다. 메일에는 **점수를 담지 않는다** (ADR-0007).
- **포기한 것**: 발송 업체의 도달률 통계·반송 관리 화면. 0원이고, 보내는 사람이 회사 주소라 신뢰도가 높다.
- **다시 볼 때**: 다우오피스의 하루 발송 한도·외부 접속 정책 때문에 막힐 때 (확인 필요: 계정당 하루 발송 한도, SMTP 외부 접속 허용 여부) → 그때 ②로 바꾼다. 바꾸는 범위는 `MailSender` 하나다.
