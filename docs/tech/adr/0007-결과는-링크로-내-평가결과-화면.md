# ADR-0007 평가결과는 메일 본문이 아니라 "내 평가결과" 화면에서

- **정해야 했던 것**: 평가결과(1차·2차·가점·최종점수·등급·상위 %)를 메일 본문에 넣을지.
- **선택지**: ① 메일 본문에 점수 (UX 원안) ② 메일은 알림과 링크만, 이메일 인증 뒤 화면에서 확인
- **고른 것**: ② (결정권자 선택, 2026-10-01). 화면 1개(S04 내 평가결과)가 늘어난다. 결과 알림 발송 뒤부터 본인만 볼 수 있고, 열람 시각을 작업 기록에 남긴다. 등급조정 여부는 화면에도 나오지 않는다.
- **포기한 것**: 메일만 열면 바로 보이는 편리함. 대신 메일이 잘못 전달되거나 메일함에 남아도 점수가 새지 않는다.
- **다시 볼 때**: 결과를 PDF 등 파일로 달라는 요구가 나올 때 (그때도 인증 후 화면에서 내려받게 한다).
