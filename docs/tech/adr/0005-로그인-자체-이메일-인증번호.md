# ADR-0005 로그인: 자체 이메일 인증번호 + 30분 세션

- **정해야 했던 것**: 극대외비라 이메일 인증이 필요하다(UX 결정). 무엇으로 만들지, 몇 분 뒤 다시 인증할지.
- **선택지**: ① Supabase 로그인 (기본 메일 발송이 시간당 몇 통 수준이라 120명 첫날에 막히고, 회사 이전을 막음) ② Auth.js 등 라이브러리 (링크 로그인 위주, 인증번호 방식은 손이 많이 감) ③ 직접 구현 (인증번호 표 + 세션 표 + 쿠키)
- **고른 것**: ③. 6자리 인증번호, 10분 유효, 5번 틀리면 무효, 다시 보내기는 60초 뒤. 같은 이메일은 1시간에 5번, 같은 접속 주소는 1시간에 30번까지만 요청할 수 있다. 인증번호와 세션 열쇠는 원문 대신 비밀값을 섞은 해시로 저장한다. 쿠키는 `HttpOnly·Secure·SameSite=Lax`. **30분 안 쓰면 끝, 최대 12시간** (결정권자 승인). 명단에 없는 이메일에도 같은 답을 준다.
- **포기한 것**: 검증된 외부 로그인 제품의 부가 기능(2단계 인증, 기기 관리 등). 범위가 작아 직접 만드는 쪽이 단순하다.
- **다시 볼 때**: 그룹웨어(다우오피스) 계정으로 한 번에 로그인하자는 요구가 나올 때 / 외부 판매를 검토할 때.
