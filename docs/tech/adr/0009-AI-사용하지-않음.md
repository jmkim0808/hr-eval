# ADR-0009 AI를 쓰지 않는다

- **정해야 했던 것**: AI 모델을 부를 곳이 있는지.
- **선택지**: ① 업적 기술 요약·첨삭, 점수 추천 등에 AI 사용 ② 사용하지 않음
- **고른 것**: ②. 도메인 문서상 점수 매기기·등급조정 판단은 사람의 몫이고, "업적 기술 편차"는 해결하지 않기로 했다. 남는 일은 모두 정해진 규칙 계산이다. 따라서 API 키도, 호출 비용도 없다.
- **포기한 것**: 업적 기술 작성 도움 같은 편의 기능.
- **다시 볼 때**: "업적 기술 편차"를 범위에 넣기로 할 때. 그때는 개인정보가 외부 AI로 나가는 문제(국외 이전·위탁 고지)를 먼저 정해야 한다.
