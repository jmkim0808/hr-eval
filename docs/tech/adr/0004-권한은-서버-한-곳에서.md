# ADR-0004 "누가 무엇을 보는지"는 서버 코드 한 곳에서 검사

- **정해야 했던 것**: 팀장은 2차 점수를 못 보고, 직원은 등급조정 여부를 모르고, 대표이사는 일부 칸만 보는 규칙을 어디서 지킬지.
- **선택지**: ① DB의 RLS 정책 ② 화면마다 각자 검사 ③ 서버의 권한 모듈 한 곳 + 데이터를 꺼내는 함수는 반드시 "누가 묻는지"를 받음
- **고른 것**: ③ (기본값과 같음). `server/authz`에 역할(본인·1차·2차·관리자·대표이사)과 단계별 허용 표를 코드로 둔다(`docs/tech/02-데이터-구조.md` 2-3). 데이터를 꺼내는 함수(`server/repo`)는 이 검사를 거쳐야만 값을 돌려주고, **허용되지 않은 칸은 아예 꺼내지 않는다**(화면에서 숨기는 것이 아님). 허용 표 전체를 자동 테스트로 확인한다.
- **포기한 것**: DB가 스스로 지켜 주는 이중 잠금. 대신 회사 DB로 옮겨도 규칙이 그대로 따라오고, 규칙이 한 파일에 모여 검토하기 쉽다.
- **다시 볼 때**: 다른 프로그램이 같은 DB에 직접 붙어야 할 때 (그때는 RLS를 추가로 건다).
