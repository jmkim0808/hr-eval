# ADR-0016 평가자가 점수를 내지 않은 채 잠겼을 때 최종점수 (결정 대기)

- **정해야 했던 것**: 관리자가 미제출자를 확인하고 단계를 넘기면 빈칸인 채로 잠긴다(업무 결정). 그런데 1차 또는 2차 평가자의 **점수가 비면** 공식(1차 60% + 2차 40%)으로 최종점수를 낼 수 없다. 직원 본인의 미제출은 점수에 영향이 없다(본인평가는 최종점수에 반영되지 않음).
- **선택지**: (결정권자에게 질문 중)
- **고른 것**: (대기) — 그때까지 계산 모듈은 해당 사람을 "계산 불가"로 표시하고 그룹 등급 산출에서 빼 둔다.
- **포기한 것**: (대기)
- **다시 볼 때**: 결정 후 계산 모듈과 최종평가 화면의 "잘못됐을 때" 상태에 반영.
