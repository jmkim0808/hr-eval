# ADR-0019 사내 포털 앱으로 운영 (Cloudflare·Supabase 대신)

- **정해야 했던 것**: 회사가 사내 AI 앱 포털(Windows Server)에 올리는 사양을 정했다. 인사평가를 어디서 돌릴지.
- **선택지**: ① Cloudflare + Supabase 그대로 (외부 클라우드, 회사 사양과 다름) ② 사내 포털 앱으로 (Node 20, `127.0.0.1` + 배정 포트, `/hr-eval` 경로) ③ 포털과 별도 사내 서버
- **고른 것**: ②. `output: standalone` 빌드, `scripts/start.mjs --port`로 시작(127.0.0.1에서만 받음), 모든 화면·주소는 `/hr-eval` 아래(`BASE_PATH`), `/hr-eval/health`, 포털 화면 안에 끼울 수 있게 `X-Frame-Options: SAMEORIGIN`·`frame-ancestors 'self'`, 엑셀 내려받기마다 포털 DLP(`/api/dlp/exports`)에 기록, 저장소 맨 위에 `ax-app.yaml`. 포털에는 cron이 없으므로 **앱 안 예약 실행**(1분마다 메일 목록 비우기, 하루 한 번 오류 요약)으로 바꿨다. 파일은 저장하지 않는다(모든 데이터는 PostgreSQL).
- **포기한 것**: 무료 클라우드의 자동 백업·외부 접속. 사외에서는 열 수 없다(회사 VPN 정책을 따른다). DB 백업은 전산 담당자의 PostgreSQL 백업에 맡긴다(ADR-0011의 엑셀 백업은 그대로 유지).
- **다시 볼 때**: 포털 사양이 바뀔 때 / 법인(중국·베트남)까지 넓힐 때.
