# ADR-0010 평가 기록은 마감일부터 3년 보관, 삭제 전에 백업 파일 제공

- **정해야 했던 것**: 기록을 언제까지 두고, 지워 달라는 요청에 어떻게 답할지.
- **선택지**: ① 3년 보관 후 삭제 ② 5년 ③ 영구
- **고른 것**: ① (결정권자 선택). 근거는 근로기준법 제42조·시행령 제22조의 "임금의 결정·지급방법과 임금계산의 기초에 관한 서류" 3년 보존이다. 평가등급이 연봉 인상의 기초이므로 해당한다고 본다(해석 — 노무 검토 권장). `review_cycles.retain_until = 마감일 + 3년`. 기한이 되면 하루 한 번 점검이 관리자에게 알린다. 관리자가 **그해 전체 기록 백업(엑셀)을 내려받은 뒤** [삭제]를 누르면 지운다 (결정권자 요구: 삭제 시 백업 지원). 보관 기간 중 퇴사자가 삭제를 요청하면 법정 보존 사유로 지우지 않고 `access_blocked`로 열람만 막는다.
- **포기한 것**: 자동 삭제(사람 확인 없이). 사고 위험이 커서 관리자 확인을 거친다.
- **다시 볼 때**: 첫 삭제 대상이 생기는 2029년 말 (2026년 평가 마감 + 3년). **자동 점검·삭제 기능은 그때까지 미뤄 두고 2029년 평가 전에 만든다.** 백업 엑셀 내려받기는 마감 기능과 함께 지금 만든다.
