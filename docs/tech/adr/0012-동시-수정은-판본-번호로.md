# ADR-0012 여러 창·여러 사람이 동시에 고칠 때: 판본 번호로 막기

- **정해야 했던 것**: 한 사람이 창을 두 개 열거나, 관리자 두 명이 동시에 등급조정·단계 넘기기를 할 때 내용이 덮어써지는 문제.
- **선택지**: ① 나중에 저장한 쪽이 이김 ② 판본 번호(낙관적 잠금) ③ 실시간 동시 편집
- **고른 것**: ②. `evaluations.version`, `review_cycles.version`을 저장할 때마다 1씩 올리고, 화면이 가진 번호와 다르면 저장하지 않고 "다른 창(사람)이 먼저 고쳤습니다 — 새로 불러오기"를 보여 준다. 단계 넘기기·확정·등급조정 적용은 정기평가 한 줄의 판본 번호로 한 번에 한 명만 성공한다.
- **포기한 것**: 두 창의 내용을 자동으로 합쳐 주는 기능.
- **다시 볼 때**: 충돌 안내가 자주 나온다는 불만이 생길 때.
