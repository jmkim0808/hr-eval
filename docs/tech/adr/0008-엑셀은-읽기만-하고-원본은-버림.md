# ADR-0008 엑셀: 서버에서 바로 읽고 원본은 저장하지 않음

- **정해야 했던 것**: 직원 명단·가점 엑셀을 어떻게 받고 어디에 둘지, 최종결과 엑셀을 어떻게 만들지.
- **선택지**: ① 파일 저장소에 원본 보관 후 처리 ② 서버가 받은 즉시 읽어 줄 단위로 저장, 원본은 버림 ③ 브라우저에서 읽어 결과만 전송
- **고른 것**: ②. 라이브러리는 ExcelJS(읽기·쓰기 겸용) 하나. 1MB 이하 `.xlsx`만, 최대 1,000줄, **제목 줄이 템플릿과 글자 하나까지 같아야** 받는다. 미리보기 때 한 번, [반영하기] 때 한 번 더 같은 검사를 한다. 내려받는 엑셀에서 `= + - @`로 시작하는 글자는 앞에 `'`를 붙여 수식으로 실행되지 않게 한다. 템플릿은 서버가 그때그때 만들어 준다.
- **포기한 것**: 올린 원본을 나중에 다시 열어 보는 기능. 극대외비 원본이 서버에 쌓이지 않는 쪽을 택했다. 브라우저에서 읽는 방식(③)은 검사 규칙이 둘로 나뉘어 뺐다.
- **다시 볼 때**: 엑셀 줄이 1,000줄을 넘을 때 (3법인 통합 등) / Workers 처리 시간 한도에 걸릴 때.
