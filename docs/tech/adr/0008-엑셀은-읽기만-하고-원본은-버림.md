# ADR-0008 엑셀: 브라우저에서 읽고 만들고, 서버는 결과만 다시 검사. 원본은 저장하지 않음

- **정해야 했던 것**: 직원 명단·가점 엑셀을 어떻게 받고, 최종결과·백업 엑셀을 어떻게 만들지. Cloudflare 무료 한도(요청당 CPU 10ms, 크기 3MB) 안에 들어야 한다(ADR-0002).
- **선택지**: ① 파일 저장소에 원본 보관 후 서버 처리 ② 서버가 받은 즉시 읽기 ③ **브라우저에서 읽고 만들기**, 서버는 줄 단위 결과만 받아 다시 검사
- **고른 것**: ③. 라이브러리는 ExcelJS 하나이고 **관리자 화면에서만 브라우저로 불러온다**(서버 프로그램 크기에 들어가지 않음). 올리기: 브라우저가 1MB 이하 `.xlsx`, 1,000줄, **템플릿과 똑같은 제목 줄**을 확인하고 줄 목록(JSON)만 서버로 보낸다 → 서버가 zod로 같은 규칙을 **다시** 검사해 미리보기를 돌려주고 → [반영하기] 때 한 번 더 검사해 저장한다. 내려받기: 서버는 권한 검사 후 데이터(JSON)만 주고, 브라우저가 엑셀로 만든다. `= + - @`로 시작하는 글자는 앞에 `'`를 붙여 수식으로 실행되지 않게 한다. 원본 파일은 어디에도 저장하지 않는다.
- **포기한 것**: 서버 한 곳에서만 검사하는 단순함(검사 규칙을 브라우저·서버가 공유하는 zod 스키마 하나로 맞춘다). 올린 원본을 다시 여는 기능.
- **다시 볼 때**: 유료로 바꾸거나 회사 서버로 옮겨 CPU 한도가 사라질 때(그때는 서버 처리로 단순화할 수 있다) / 줄이 1,000줄을 넘을 때.
