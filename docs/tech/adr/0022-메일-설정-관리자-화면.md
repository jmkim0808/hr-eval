# ADR-0022 메일 발송 설정을 관리자 화면에서 바꾼다

- 날짜: 2026-10-26
- 상태: 채택

## 배경
인사평가 담당 관리자가 1명이고, 담당자가 바뀌거나 보내는 계정 비밀번호가 바뀔 때마다 전산 담당자에게 서버 환경 값을 고쳐 달라고 할 수 없다. 관리자가 독촉 메일 등을 원하는 계정으로 보내길 원한다.

## 결정
1. 관리자 화면 [메일 발송]에서 SMTP 서버·포트·계정·비밀번호·보내는 사람을 넣는다 (`mail_settings` 한 줄).
2. **저장 전에 관리자 본인 메일로 시험 메일을 보내고, 성공해야 저장**한다. 틀린 설정으로 로그인 인증번호가 막히는 일을 막는다.
3. 비밀번호는 **서버 비밀값(`AUTH_SECRET`)으로 암호화**한다. 평가 내용 보안 열쇠(ADR-0021)를 쓰지 않는다 — 서버가 다시 켜져 열쇠가 잠겨 있어도 로그인 인증번호 메일은 나가야 하므로. DB만 새어 나가면 알아볼 수 없다.
4. 보낼 때는 화면 설정 → 없으면 서버 환경 값(`SMTP_*`). 화면 설정이 연결·로그인에서 실패하면 **서버 환경 값으로 한 번 더** 보내고, 화면에 경고를 띄운다. 그래서 서버 환경 값은 **필수**다 — 처음 관리자 로그인 인증번호도 이것으로 나간다.
5. 화면에는 비밀번호를 돌려주지 않는다. 작업 기록에는 서버 주소·포트만 남긴다.

## 결과·한계
- 서버 관리자는 `AUTH_SECRET`과 DB를 함께 보면 비밀번호를 풀 수 있다 (환경 값에 직접 넣는 것과 같은 수준).
- `AUTH_SECRET`을 바꾸면 화면 설정 비밀번호를 풀 수 없어 서버 환경 값으로 보낸다 → 관리자가 다시 저장한다.
