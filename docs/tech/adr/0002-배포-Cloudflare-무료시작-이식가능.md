# ADR-0002 배포: Cloudflare Workers — 무료로 시작, 막히면 유료(월 5달러), 회사 서버로 옮길 수 있게

- **정해야 했던 것**: 프로그램을 어디서 돌릴지. 기본값은 Vercel이었다.
- **선택지**: ① Vercel 무료 — 약관상 회사 업무용(상업적 사용) 불가 ② Vercel 유료 월 20달러 ③ Netlify 무료 ④ Cloudflare 무료 — 프로그램 크기 3MB, 요청 한 번당 CPU 10ms 한도 ⑤ Cloudflare 유료 월 5달러 ⑥ 회사 서버
- **고른 것**: ④ **Cloudflare 무료로 시작** (결정권자 결정, 2026-10-01 — 처음엔 ⑤를 골랐다가 무료로 바꿈). Next.js는 OpenNext 어댑터(`@opennextjs/cloudflare`)로 올린다. 무료 한도 안에 들도록 세 가지를 지킨다: (1) **엑셀 읽기·만들기는 브라우저에서** 한다(ADR-0008) — 서버 CPU와 프로그램 크기를 아끼기 위해, (2) 서버는 화면 그리기·권한 검사·저장만 하고 무거운 계산을 하지 않는다(120명 등급 계산은 1ms 미만 — 추정), (3) 메일은 한 번에 10통씩만 보낸다(기다리는 시간은 CPU에 들어가지 않음). 같은 코드를 Node.js(`output: "standalone"`)로도 빌드할 수 있게 유지한다.
- **포기한 것**: 한도 걱정 없는 안정성. 0원 대신, 한도에 걸리면 화면이 가끔 "오류 1102"로 뜰 수 있다. Cloudflare 전용 기능(KV, D1, R2, Durable Objects)은 회사 서버 이전을 막으므로 쓰지 않는다.
- **다시 볼 때 (유료로 바꾸는 조건)**: ① Cloudflare 로그에 CPU 한도 초과(1102)가 하루 1건이라도 보일 때 ② 빌드한 프로그램이 압축 후 3MB를 넘을 때 ③ 평가 시작(11월) 2주 전 점검에서 위 둘 중 하나가 보일 때. 바꾸는 방법은 Cloudflare 대시보드에서 Workers Paid(월 5달러) 결제 한 번이며 코드는 바꾸지 않는다. 내부 공유 후 "외부 서버 vs 회사 서버"를 결정할 때도 다시 본다.
