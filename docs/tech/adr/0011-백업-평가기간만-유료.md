# ADR-0011 백업: 평가 기간만 Supabase 유료, 나머지는 무료 + 깨우기 + 마감 백업 (비용 승인 대기)

- **정해야 했던 것**: Supabase 무료 플랜은 7일 동안 안 쓰면 멈추고, 자동 백업이 없다. 이 서비스는 1년 중 10달을 쉰다.
- **선택지**: ① 1년 내내 무료 ② 평가 기간(약 10~12월)만 Pro(월 25달러) ③ 1년 내내 Pro
- **고른 것**: ② (추천안 — **비용이 드는 결정이라 결정권자 승인 대기**. 승인 전까지는 ①로 운영한다). 평가 시작 전(10월)에 Pro로 올리고, 마감 후(12월~1월)에 무료로 내린다. Pro 기간에는 매일 자동 백업(7일치)이 있다. 1년 내내 하루 한 번 예약 실행이 DB에 가벼운 조회를 보내 멈춤을 막는다. 평가 마감 때 관리자가 **그해 전체 기록 엑셀**을 내려받아 사내 보안 저장소에 둔다. Pro 기간에는 사용량 상한(Spend Cap)을 켜서 초과 요금이 나오지 않게 한다.
- **포기한 것**: 쉬는 10달 동안의 자동 백업. 그 기간에는 데이터가 바뀌지 않으므로 마감 백업으로 충분하다고 본다.
- **다시 볼 때**: 회사 서버로 옮길 때 (그때는 회사 백업 정책을 따름) / 쉬는 기간에도 데이터를 바꾸는 기능이 생길 때 / 자동 깨우기가 Supabase 정책상 막힐 때.
