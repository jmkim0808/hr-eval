# ADR-0015 그룹별 등급 인원의 반올림 합계가 맞지 않으면 B 등급에서 맞춘다

- **정해야 했던 것**: 도메인 결정은 "등급별 인원은 반올림"이다. 그런데 그룹마다 따로 반올림하면 합계가 그룹 인원과 달라진다. 예: 10명 그룹 → S 0.5→1, A 2, B 6, C 1.5→2, D 0.5→1 = **12명**.
- **선택지**: ① 남거나 모자라는 인원을 B에서 맞춤 ② 위에서부터 누적 비율로 자름 ③ 초안은 ①로 내고 관리자가 등급조정으로 직접 맞춤
- **고른 것**: ① (결정권자 결정, 2026-10-01). S·A·C·D는 각각 반올림(0.5는 올림)하고, **B = 그룹 인원 − (S+A+C+D)** 로 정한다. 위 예시는 S 1 · A 2 · B 4 · C 2 · D 1 = 10명이다. B가 0보다 작아지는 아주 작은 그룹(2명 이하 등)이면 C → A → D → S 순서로 1명씩 줄여 B를 0으로 맞춘다. 계산 모듈 테스트에 10명·3명·42명 예시를 넣는다.
- **포기한 것**: 작은 그룹에서 B 비율(60%)을 정확히 지키는 것. 대신 양 끝 등급(S·D)이 늘지 않고 설명이 쉽다.
- **다시 볼 때**: 등급 비율이 바뀔 때 / 그룹 구성이 바뀔 때.
