# 04. 직원이 링크로 들어와 내 할 일에서 평가지를 쓰고 제출한다

## 할 일
- 직원·팀장의 이메일 인증 → 내 할 일.
- 평가지 작성: 본인평가(역량 10개), 업적 기술 두 칸, 저절로 임시저장, [제출].
- 기간 안에서는 제출 뒤에도 다시 열어 고칠 수 있음.
- 내 할 일의 상태 표시: 작성 전 / 작성 중 / 제출 완료 — 기한까지 고칠 수 있습니다 / 기한 지남.

## 확인 문장
- [ ] 안내 메일 링크를 누르고 인증하면 내 할 일이 열리고 맨 위에 "내 평가지 작성 — 마감 (날짜)"가 크게 보인다.
- [ ] 팀원에게는 팀원용 10개 항목, 팀장에게는 팀장역량(리더쉽·소통·계획)이 들어간 팀장용 항목이 보인다.
- [ ] 평가자 점수 칸과 가점 칸은 보이지 않고 "가점은 관리자가 입력합니다"가 보인다.
- [ ] 쓰다가 1~2초 멈추면 "저장됨 (시각)"이 보이고, 창을 닫았다 다시 열어도 쓰던 내용이 그대로 있다.
- [ ] 업적 칸이 비었는데 [제출]을 누르면 그 칸이 빨간 테두리로 표시되고 고칠 방법이 보인다.
- [ ] 제출하면 내 할 일에 "제출 완료 — (날짜)까지 고칠 수 있습니다"가 보인다.
- [ ] 제출한 뒤 다시 열어 고치고 저장할 수 있다.
- [ ] 같은 평가지를 창 두 개로 열어 한쪽에서 고친 뒤 다른 쪽에서 저장하면 "다른 창에서 고친 내용이 있습니다"가 보인다.
- [ ] 기간이 지나도 계속 쓸 수 있고 "기한 지남"이 보인다.
- [ ] 다른 사람의 평가지 주소를 직접 넣어도 열리지 않는다.
