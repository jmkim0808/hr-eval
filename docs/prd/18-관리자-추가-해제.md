# 18. 관리자가 다른 사람을 관리자로 추가하거나 해제한다

## 할 일
- 관리자 설정: 관리자 목록, [관리자 추가](이메일), [해제]. 마지막 1명은 해제 불가.
- 추가·해제는 작업 기록에 남음.

## 확인 문장
- [ ] 이메일을 넣고 [관리자 추가]를 누르면 목록에 나타나고, 그 사람이 인증하면 진행 현황이 열린다.
- [ ] 이메일 형식이 틀리면 "이메일 주소 형식이 아닙니다"가 보인다.
- [ ] 관리자가 1명만 남으면 [해제]가 눌리지 않고 "마지막 관리자는 해제할 수 없습니다"가 보인다.
- [ ] 해제된 사람은 다음 화면 이동 때 관리자 화면에 들어갈 수 없다.

## 이번에 안 할 것
- 관리자 권한 등급 나누기

## 바뀐 것
- 없음

## 2026-10-26 추가: 관리자이면서 피평가자

- 인사평가 담당자가 1명이라, 관리자도 명단에 있으면 직원과 똑같이 본인 평가지를 쓰고 평가받는다.
- 관리자는 본인 기록(가점·빈 점수 대신 입력·등급 조정·대표이사 조정 대신 입력·평가자 바꾸기)도 고칠 수 있다. 관리자 화면에서 본인 결과도 그대로 보인다.
- 대신 본인 기록을 고치면 작업 기록에 **본인 기록**으로 따로 남고, 전체 백업 엑셀의 **"관리자 본인 기록 수정"** 시트에 언제·누가·무엇을이 모인다 (등급 값은 남기지 않음).

확인 문장
- [ ] 관리자가 명단에 있으면 내 할 일에 '내 평가지 작성'이 보인다
- [ ] 관리자가 본인 가점을 넣으면 작업 기록에 본인 기록으로 남고, 남의 가점은 표시가 없다
- [ ] 전체 백업 엑셀에 '관리자 본인 기록 수정' 시트가 있다

## 2026-10-26 추가: 메일 발송 설정 (ADR-0022)

- [메일 발송] 화면에서 보내는 계정을 바꾼다. 시험 메일이 관리자 본인에게 가야 저장된다. 비밀번호는 화면에 다시 보이지 않는다.

확인 문장
- [ ] 포트 등이 틀리면 저장하지 않고 이유가 보인다
- [ ] 저장하면 '이 화면 설정'으로 보이고 비밀번호는 화면에 없다
- [ ] 비밀번호 칸을 비우고 저장하면 저장된 비밀번호를 그대로 쓴다
- [ ] 화면 설정이 실패하면 서버 기본 설정으로 보내고 화면에 경고가 뜬다
