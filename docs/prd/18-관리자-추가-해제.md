# 18. 관리자가 다른 사람을 관리자로 추가하거나 해제한다

## 할 일
- 관리자 설정: 관리자 목록, [관리자 추가](이메일), [해제]. 마지막 1명은 해제 불가.
- 추가·해제는 작업 기록에 남음.

## 확인 문장
- [ ] 이메일을 넣고 [관리자 추가]를 누르면 목록에 나타나고, 그 사람이 인증하면 진행 현황이 열린다.
- [ ] 이메일 형식이 틀리면 "이메일 주소 형식이 아닙니다"가 보인다.
- [ ] 관리자가 1명만 남으면 [해제]가 눌리지 않고 "마지막 관리자는 해제할 수 없습니다"가 보인다.
- [ ] 해제된 사람은 다음 화면 이동 때 관리자 화면에 들어갈 수 없다.

## 이번에 안 할 것
- 관리자 권한 등급 나누기

## 바뀐 것
- 없음
