# 19. 관리자가 오류가 생긴 날 다음 날 아침 요약 메일을 받는다

## 할 일
- 예상 못 한 오류가 나면 화면에 "문제가 생겼습니다. 요청 번호 ○○"만 표시.
- 지난 24시간에 오류가 있으면 아침 8시에 관리자에게 건수와 요청 번호 메일.
- 하루 한 번 DB 깨우기.

## 확인 문장
- [ ] 오류가 난 화면에는 요청 번호만 보이고 이름·점수 같은 내용은 보이지 않는다.
- [ ] 오류가 있던 다음 날 아침 8시 무렵 관리자 메일함에 "오류 N건"과 요청 번호가 온다.
- [ ] 오류가 없던 날에는 메일이 오지 않는다.
- [ ] 요약 메일에 이름·이메일·점수가 들어 있지 않다.
