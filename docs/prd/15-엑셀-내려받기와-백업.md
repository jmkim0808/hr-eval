# 15. 관리자가 최종결과 엑셀과 전체 기록 백업 엑셀을 내려받는다

## 할 일
- 결과 발송 화면의 [최종결과 엑셀 내려받기](확정 뒤).
- 관리자 화면의 [전체 기록 백업 내려받기]: 명단·평가지·점수·가점·최종평가·등급조정 이력.
- 단계를 넘길 때와 확정할 때 "지금 백업을 내려받아 보관하세요" 안내.

## 확인 문장
- [ ] 확정 전에는 [최종결과 엑셀 내려받기]가 눌리지 않는다.
- [ ] 내려받은 최종결과 엑셀에 이름·부서·그룹·최종점수·평가등급이 있고 화면 숫자와 같다.
- [ ] "="로 시작하는 이름이나 글이 있어도 엑셀에서 수식으로 실행되지 않는다.
- [ ] 다음 단계로 넘기기와 확정 직후 백업 안내가 보인다.
- [ ] 백업 엑셀에 시트가 나뉘어 있고, 등급조정 이력(누가·언제·무엇을)이 들어 있다.
- [ ] 백업을 내려받으면 작업 기록에 남는다.
