# 14. 관리자가 평가등급을 확정하고, 필요하면 결과 알림 전까지 확정을 취소한다

## 할 일
- 최종평가의 [확정]. 점수 빈칸이 남으면 누를 수 없음. 가점 미반영자가 있으면 경고.
- 확정 뒤 "확정됨 (날짜, 확정자)", 가점 입력 잠김.
- [확정 취소]: 사유 입력, 다른 관리자에게 알림 메일, 결과 알림 발송 전까지만. 취소해도 가점은 다시 열리지 않음.

## 확인 문장
- [ ] 점수 빈칸이 있으면 [확정]이 눌리지 않고 이유가 보인다.
- [ ] 확정하면 "확정됨 (날짜, 확정자)"가 보이고 등급 칸을 누를 수 없다.
- [ ] 확정 뒤 가점 입력 화면이 보기 전용이 되고 "평가등급이 확정되어 가점을 더 이상 인정하지 않습니다"가 보인다.
- [ ] [확정 취소]는 사유를 적어야 눌리고, 누르면 다른 관리자에게 메일이 간다.
- [ ] 확정을 취소해도 가점 입력은 열리지 않는다.
- [ ] 결과 알림을 보낸 뒤에는 [확정 취소]가 보이지 않는다.
