# 01. 관리자가 이메일 인증으로 들어와 진행 현황을 본다

## 할 일
- 관리자 2명(파트장·경영지원실장)을 처음 관리자로 등록해 둔다.
- 이메일 인증 화면: 이메일 입력 → 인증번호 메일 → 인증번호 입력 → 들어가기.
- 관리자는 진행 현황으로 들어가고, 처음에는 "아직 시작한 평가가 없습니다"와 [평가 시작 설정]만 보인다.
- 모든 화면 맨 위에 머리줄과 "대외비 · 열람자 ○○○"를 표시한다.
- 30분 동안 안 쓰면 다시 인증해야 한다.

## 확인 문장
- [ ] 관리자 이메일을 넣으면 인증번호 메일이 회사 메일(다우오피스)로 온다.
- [ ] 인증번호를 넣으면 진행 현황이 열리고 "아직 시작한 평가가 없습니다"가 보인다.
- [ ] 틀린 번호를 넣으면 "번호가 맞지 않습니다"가, 10분이 지나면 "시간이 지났습니다"가 보인다.
- [ ] 5번 틀리면 그 번호로는 들어갈 수 없고 다시 받아야 한다.
- [ ] [다시 보내기]는 60초가 지나야 눌린다.
- [ ] 명단에 없는 이메일을 넣어도 화면에는 똑같이 "보냈습니다"가 보이고, 메일은 오지 않는다.
- [ ] 30분 동안 아무것도 하지 않고 다시 누르면 이메일 인증 화면으로 간다.
- [ ] 오른쪽 위에 "대외비 · 열람자 (내 이름)"이 보인다.
