# 09. 관리자가 가점을 템플릿으로 한 번에 올리거나 한 사람씩 입력한다

## 할 일
- 가점 입력 화면: [템플릿 내려받기], [템플릿 올리기] → 미리보기(일치·이름 불일치) → [반영하기].
- 가점 표: 자격증·포상·직무발명보상·교육참여도·징계사항·내부회계관리제도·다면평가(팀장만)·합계.
- 줄을 눌러 한 사람씩 입력. 단계와 상관없이 확정 전까지.

## 확인 문장
- [ ] 템플릿에 항목별 칸이 있고, 다면평가 칸은 팀장 줄에만 입력할 수 있다.
- [ ] 올리면 "N명 중 M명 일치 · 이름이 맞지 않는 K명"이 보이고, 맞지 않는 사람은 따로 표시된다.
- [ ] [반영하기] 뒤 가점 표에 항목별 점수와 합계가 보인다.
- [ ] 징계사항은 음수로 넣을 수 있고 합계에서 빠진다.
- [ ] 팀원 줄의 다면평가 칸은 "—"로 보이고 입력할 수 없다.
- [ ] 2차평가 기간 전이어도 가점을 넣을 수 있다.
- [ ] 진행 현황에 "가점 반영 N / 120"이 보인다.
