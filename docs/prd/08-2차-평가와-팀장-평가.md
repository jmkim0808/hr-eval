# 08. 임원이 1차 점수를 보며 2차 평가와 팀장 평가를 한다

## 할 일
- 임원의 내 할 일: "2차 평가" 묶음과 "팀장 평가" 묶음.
- 평가하기에서 본인평가·1차(팀장) 점수 옆에 2차 점수 칸.
- 팀장 평가지는 임원이 하나의 평가로 입력. 둘 다 2차평가 기간에만.

## 확인 문장
- [ ] 2차평가 기간에 임원이 열면 1차(팀장) 점수가 옆 칸에 보이고 2차 칸에 입력할 수 있다.
- [ ] 팀장 평가 묶음에 담당 팀장들이 보이고, 팀장용 항목(리더쉽·소통·계획 포함)에 점수를 넣을 수 있다.
- [ ] 1차평가 기간에는 같은 화면이 보기만 된다.
- [ ] 내가 맡지 않은 사람의 평가지는 열리지 않는다.
- [ ] 다 끝나면 묶음마다 "N명 중 N명 완료"가 보인다.
