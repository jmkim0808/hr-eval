# 03. 관리자가 기간을 정하고 안내 이메일을 보내 개인작성 기간을 연다

## 할 일
- 평가 시작 설정의 ③ 기간(개인작성·1차평가·2차평가 기간, 가점 인정 기준일), ④ 안내 이메일 미리보기.
- [안내 이메일 발송] → 보낼 메일 목록에 쌓고 나눠 보냄, 발송 진행 숫자.
- 발송하면 단계가 "개인작성"이 되고 진행 현황의 단계 줄에 표시된다.
- 발송 실패자 명단과 [다시 보내기].

## 확인 문장
- [ ] 명단 또는 기간이 비어 있으면 [안내 이메일 발송]이 눌리지 않는다.
- [ ] 1차평가 기간이 개인작성 기간보다 앞서면 "1차평가 기간이 끝난 뒤로 정해 주세요" 같은 안내가 보인다.
- [ ] 누르면 "발송 중 N / 120"이 보이고, 화면을 떠났다 와도 숫자가 계속 올라간다.
- [ ] 끝나면 "발송 완료 N · 실패 M"과 실패한 사람 이름이 보이고 [다시 보내기]를 누를 수 있다.
- [ ] 받은 메일에는 개인작성 기간, 가점 인정 기준일, 들어오는 링크가 있고 점수는 없다.
- [ ] 진행 현황 단계 줄에서 "개인작성"이 지금 단계로 표시된다.
- [ ] 발송한 뒤에는 명단을 다시 올릴 수 없다.
