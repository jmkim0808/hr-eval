# 13. 대표이사가 등급 결과를 직접 보고, 조정이 바로 반영되는 것을 본다

## 할 일
- 대표이사 이메일 등록, 이메일 인증 → 등급 결과(보기만).
- 그룹 고르기(크게), 등급별 인원, 순위·이름·부서·직급·최종점수·등급·조정 표시.
- 10초마다 새로 읽어 조정이 반영됨.

## 확인 문장
- [ ] 대표이사가 인증하면 바로 등급 결과가 열리고 메뉴가 없다.
- [ ] 최종평가 전에는 "아직 보고할 결과가 없습니다"가 보인다.
- [ ] 관리자가 [적용]하면 10초 안에 대표이사 화면의 등급과 조정 표시가 바뀐다.
- [ ] 대표이사 화면에는 고치는 칸과 버튼이 하나도 없다.
- [ ] 업적 글, 항목별 점수, 가점 내역은 보이지 않는다.

## 이번에 안 할 것
- 대표이사 계정 관리 화면 (관리자 설정에 넣지 않음, 처음 등록만)
