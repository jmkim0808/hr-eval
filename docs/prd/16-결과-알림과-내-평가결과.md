# 16. 관리자가 평가결과 알림을 보내고, 직원이 내 평가결과 화면에서 결과를 본다

## 확인 문장
- [ ] 받은 메일에 점수·등급이 없고 "결과가 나왔습니다"와 링크만 있다.
- [ ] 인증하면 내 평가결과에 1차 점수, 2차 점수, 가점(항목별), 최종점수, 평가등급, 상위 %가 보인다.

- [ ] "조정", "밀려남" 같은 말은 어디에도 보이지 않는다.
- [ ] 발송 전에는 내 평가결과가 "아직 결과가 나오지 않았습니다"로 보인다.
- [ ] 다른 사람의 결과 주소를 넣어도 열리지 않는다.
