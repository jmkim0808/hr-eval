# 05. 관리자가 진행 현황에서 미제출자를 찾고 독촉 이메일을 보낸다

## 할 일
- 진행 현황: 단계 줄, 제출·미제출 숫자, 미제출자 표(이름·부서·역할·상태·마지막 독촉).
- 미제출자를 골라 [독촉 이메일]. 발송 진행·실패 표시.
- 미제출자 이름을 누르면 그 평가지를 보기 전용으로 연다.

## 확인 문장
- [ ] 직원이 제출하면 진행 현황을 다시 열었을 때 제출 숫자가 1 늘고 미제출자 표에서 빠진다.
- [ ] 미제출자 표에 작성 전 / 작성 중이 구분되어 보인다.
- [ ] 몇 명을 골라 [독촉 이메일]을 누르면 그 사람들에게만 메일이 가고 "마지막 독촉" 날짜가 오늘로 바뀐다.
- [ ] 미제출자 이름을 누르면 그 사람이 쓰던 평가지가 고칠 수 없는 상태로 열린다.
- [ ] 기간이 지난 단계는 단계 줄에 "기한 지남"이 보인다.
