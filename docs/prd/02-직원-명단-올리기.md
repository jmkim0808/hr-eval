# 02. 관리자가 직원 명단 엑셀을 올려 평가 대상·그룹·평가자를 정한다

## 할 일
- 평가 시작 설정 화면의 ① 직원 명단, ② 대상자 표.
- 직원 명단 템플릿 내려받기 (이름·이메일·부서·직급·입사일·팀장 여부·담당 임원).
- 올리면 미리보기: 반영·제외(6월 30일 이후 입사)·확인 필요(빈칸·형식 오류) 인원.
- [반영하기] 뒤 대상자 표: 그룹(1~5), 평가지 종류(팀원용/팀장용), 1차·2차 평가자 자동 채움, 평가자는 고를 수 있음.

## 확인 문장
- [ ] [템플릿 내려받기]로 받은 엑셀의 제목 줄이 이름·이메일·부서·직급·입사일·팀장 여부·담당 임원이다.
- [ ] 7월 1일 이후 입사자는 미리보기에서 "제외"로 나오고 대상자 표에 들어가지 않는다.
- [ ] 이메일이 빈 줄이 있으면 "확인 필요"로 나오고 [반영하기]가 눌리지 않는다.
- [ ] 제목 줄이 템플릿과 다르거나 .xlsx가 아니거나 1MB를 넘으면 반영 전에 이유가 보인다.
- [ ] 팀장 여부가 "예"인 사람은 평가지 종류가 팀장용, 1차 평가자가 담당 임원, 2차 평가자가 "—"이다.
- [ ] 팀원의 1차 평가자는 같은 부서 팀장, 2차 평가자는 담당 임원이다.
- [ ] 부서이동자의 평가자를 표에서 다른 사람으로 바꾸면 다시 열어도 바뀐 채로 남아 있다.
- [ ] 직급이 대리이하인 사람은 5그룹, 팀장은 1그룹으로 보인다.
- [ ] 명단을 다시 올리면 이전 명단이 새 명단으로 바뀐다(안내 이메일 발송 전까지만).
