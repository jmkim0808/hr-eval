# 17. 관리자가 연봉조정까지 확인하고 그해 평가를 마감한다

## 할 일
- 결과 발송의 [평가 마감](확인 창). 실패자가 남아도 마감 가능(수기 전달).
- 마감 뒤 그해 평가는 보기 전용 기록, 진행 현황에 마감 표시, 보관 기한(마감 + 3년) 표시.
- 마감 때 백업 내려받기 안내.

## 확인 문장
- [ ] [평가 마감]을 누르면 "연봉조정까지 끝났나요?" 확인 창이 뜬다.
- [ ] 마감하면 진행 현황에 "2026년 정기평가 마감 (날짜, 마감자)"와 단계 줄 전부 ✔가 보인다.
- [ ] 마감 뒤에는 모든 화면이 보기 전용이다.
- [ ] 보관 기한(마감일 + 3년)이 보인다.
- [ ] 메일 실패자가 남아 있어도 마감할 수 있고, 실패 명단은 계속 볼 수 있다.
