# 07. 팀장이 팀원 평가지에 1차 평가를 한다

## 할 일
- 팀장의 내 할 일: "1차 평가 — 팀원 N명 중 M명 남음" 묶음.
- 평가하기: 왼쪽 팀원 목록, 오른쪽 본인평가·업적 글(읽기)과 1차 점수 칸, [제출]·[다음 사람].
- 팀원이 제출하는 순간부터 팀장·임원이 볼 수 있음. 점수는 1차평가 기간에만.

## 확인 문장
- [ ] (2026-10-02 추가) 묶음의 마지막 사람을 제출할 때 내 평균이 80 ± 0.5를 벗어나면 제출이 막히고 몇 점을 어떻게 고칠지 보인다. 2명 이하는 예외.
- [ ] 개인작성 기간에도 팀장은 팀원이 제출한 평가지를 볼 수 있지만 점수 칸은 없다.
- [ ] 1차평가 기간에는 역량 10개와 업적 점수를 1~10으로 넣을 수 있다.
- [ ] 11 같은 범위 밖 숫자는 저장되지 않고 이유가 보인다.
- [ ] [제출] 뒤 [다음 사람]을 누르면 같은 묶음의 다음 팀원이 열린다.
- [ ] 다 끝나면 내 할 일에 "8명 중 8명 완료"가 보이고 묶음이 아래로 내려간다.
- [ ] 팀장 화면 어디에도 2차(임원) 점수 칸이나 숫자가 보이지 않는다.
- [ ] 같은 시기에 임원이 들어오면 같은 평가지가 보기만 되고 "2차평가 기간에 입력할 수 있습니다"가 보인다.
- [ ] 내 팀원이 아닌 사람의 평가지는 열리지 않는다.
