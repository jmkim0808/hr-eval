# 12. 관리자가 등급을 바꾸면 밀려나는 사람을 미리 보고 적용하거나 되돌린다

## 할 일
- 최종평가 표의 등급 칸을 눌러 새 등급 고르기 → "이렇게 바뀝니다" 확인 창 → [적용].
- 조정된 줄과 밀려난 줄 표시(↑ 조정 · 상향 / ↓ 밀려남 · 하향), 줄마다 [되돌리기].
- 최종점수는 그대로.

## 확인 문장
- [ ] A인 사람을 S로 바꾸면 확인 창에 그 사람과 S 최하단에서 A로 내려갈 사람이 함께 보인다.
- [ ] S인 사람을 A로 바꾸면 A 최상단에서 S로 올라갈 사람이 함께 보인다.
- [ ] [적용] 뒤 그룹의 등급별 인원은 그대로이고, 두 사람 줄에 파란 "↑ 조정 · 상향" / 빨간 "↓ 밀려남 · 하향"이 글자와 함께 보인다.
- [ ] 조정해도 두 사람의 최종점수 숫자는 바뀌지 않는다.
- [ ] [되돌리기]를 누르면 두 사람이 원래 등급으로 돌아간다.
- [ ] 관리자 두 명이 동시에 다른 조정을 적용하면 나중 사람에게 "다른 관리자가 먼저 처리했습니다"가 보인다.
