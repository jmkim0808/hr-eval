# 11. 관리자가 평가자에게 받은 빈 점수를 대신 입력한다

## 할 일
- 최종평가의 "점수 빈칸" 줄을 누르면 평가하기(관리자 모드)가 열리고 빈 칸에만 입력 가능.
- 입력하면 누가 대신 넣었는지 기록되고 그 그룹 초안을 다시 계산.

## 확인 문장
- [ ] 빈 칸에만 입력할 수 있고 이미 들어간 점수는 고칠 수 없다.
- [ ] 입력한 칸 옆에 "관리자 대신 입력 (이름)"이 보인다.
- [ ] 저장하면 최종평가 화면에서 그 사람에게 최종점수와 등급이 생긴다.
- [ ] 다시 계산으로 등급 경계가 바뀐 사람이 있으면 그 줄에 표시가 보인다.
