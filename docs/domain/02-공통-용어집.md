# 2. 공통 용어집

> 인터뷰에서 도메인 전문가가 쓴 말을 그대로 기준으로 삼는다. 화면·문서·대화에서 아래 말을 다른 말로 바꿔 부르지 않는다.

| 용어 | 실제로 가리키는 것 | 비고 |
|---|---|---|
| **정기평가** | 매년 11월 한 달 동안 진행하는 연 1회 인사평가. 결과 등급은 연봉조정에 쓰인다 | KPI 관리 방식이 아님 |
| **평가지 / 인사평가지** | "㈜파워넷 역량 / 업적 평가표". 한 사람당 한 장 | 현재 엑셀 파일 |
| **팀원용 인사평가지** | 팀원이 작성하고 팀장(1차)·임원(2차)이 평가하는 평가지 | |
| **팀장용 인사평가지** | 팀장이 작성하고 임원이 평가(1차만)하는 평가지. 팀장역량 항목과 다면평가 가점이 있음 | |
| **빈 양식** | 전사공지로 배포하는 작성 전 평가지 | |
| **전사공지** | 평가 시작을 전 직원에게 알리는 공지. 제출 기한·가점 인정 기준일 포함 | |
| **피평가자** | 평가를 받는 사람. 평가지의 하늘색 음영 칸을 채운다 | |
| **본인평가** | 피평가자가 역량 항목에 스스로 매기는 점수 | 최종 점수에 반영되지 않음 |
| **1차 평가** | 팀원 평가지에 대한 팀장의 평가 (비중 60%) | 팀장용 평가지는 임원 평가가 1차이자 유일한 평가 |
| **2차 평가** | 팀원 평가지에 대한 임원의 평가 (비중 40%) | |
| **역량 평가** | 10개 역량 항목을 1~10점으로 평가. 전체의 30% | 1 미흡 · 약간 미흡 · 5 보통 · 우수 · 10 탁월 |
| **업적 평가** | 피평가자가 적은 "개인역할 및 업적 / 차년도 개선 및 발전"을 보고 평가자가 매기는 점수 하나. 전체의 70% | |
| **업적 기술** | 피평가자가 업적 평가란에 직접 쓰는 내용 | 잘 쓰는 사람과 못 쓰는 사람의 편차가 있음 |
| **가점** | 평가 점수에 더하는 추가 점수. 자격증·포상·직무발명보상·교육참여도·징계사항(감점)·내부회계관리제도, 팀장은 다면평가 추가 | 내부 규정에 따름 |
| **가점 인정 기준일** | 가점으로 인정하는 마감 시점. 11월 중순 특정 시점 | 전사공지 때 안내 |
| **가점 기반 자료 / 가점 결과표** | 개별담당자가 만드는 사람별 가점 근거 자료 | |
| **개별담당자** | 가점 항목별 기반 자료를 작성하는 담당자 | 파트장이 직접 취합하지 않음 |
| **평가 점수** | 역량 점수 × 30% + 업적 점수 × 70% + 가점 | |
| **최종평가** | 모든 평가와 가점을 합쳐 최종 점수를 산출하고 등급을 매기는 단계 | 가점은 이 단계 전에 들어가야 함 |
| **결과지** | 최종평가 결과를 취합한 표. 대표이사 보고용 | |
| **그룹 / 그룹별 상대평가** | 직급별로 나눈 다섯 그룹 안에서 점수 순으로 등급을 나누는 방식. 1그룹 팀장, 2그룹 부장, 3그룹 차장, 4그룹 과장, 5그룹 대리이하 | |
| **등급 (S~D)** | 상대평가 결과. 상위부터 S 5% · A 20% · B 60% · C 15% · D 5% | |
| **등급조정** | 대표이사 보고 후 대표이사·임원진의 판단을 추가로 반영해 등급을 바꾸는 것. 1·2차 평가자의 왜곡 보정 포함. 비율을 지키므로 경계선 인원이 연쇄로 밀린다 | |
| **평가등급 확정** | 등급조정까지 끝나 더 이상 바뀌지 않는 상태 | |
| **평가결과 오픈 / 평가 피드백** | 확정된 평가결과를 개별 직원에게 알리는 것. 현재 연봉계약서와 함께 전달 | TO-BE: 이메일 발송 |
| **이의제기** | 평가결과에 대한 직원의 문제 제기. 드물고, 대부분 연봉계약 면담 중에 나옴 | |
| **연봉조정** | 평가등급에 따라 연봉인상 폭을 달리 반영하는 일. 평가 업무의 끝 | 시스템에서는 확정 등급 엑셀 제공까지만 |
| **부서이동자** | 평가 연도 중 부서를 옮긴 직원. 최종 부서장이 평가 | |
| **상호협의** | 부서이동자의 이전 부서 기간이 길 때 이전·현재 부서장이 평가를 협의하는 것 | |
| **미제출자 독촉** | 기한 안에 평가지를 내지 않은 직원·팀장·임원에게 제출을 재촉하는 일 | 한 명만 늦어도 다음 일정이 밀림 |
| **평가 대상** | 그해 6월 말까지 입사한 직원. 약 120명 | |
