# 1. 도메인 이야기 — 연 1회 정기평가

> 출처: 도메인 스토리텔링 워크숍 (2026-09-30, 경영지원실 파트장 인터뷰)
> 적용 범위: **서울 본사 단독** (중국·베트남 법인 제외)
> 표기: 인터뷰에서 확인한 내용은 그대로 적고, 확인하지 못한 내용은 **(미정)** 으로 표시했다.

---

## 1-1. 이 일의 범위

- **무엇**: 매년 1회 진행하는 정기평가. 개인별 평가지를 배포하고, 1차 팀장·2차 임원이 항목별로 점수를 매겨 최종 **S~D 등급**을 내는 일.
- **언제**: 매년 **11월 초 시작 → 11월 말 평가 완료** → 이후 연봉조정 반영.
- **어디서 끝나는가**: 확정된 평가등급이 **연봉조정에 반영**되면 끝난다.
- **대상**: 그해 **6월 말까지 입사한 직원**, 약 **120명**.

---

## 1-2. 참여자

| 참여자 | 하는 일 |
|---|---|
| **파트장 (인사 담당자)** | 평가지 배포·분류·취합·재배포, 미제출자 독촉, 가점 입력, 최종평가 산출, 대표이사 보고, 등급조정 반영, 결과 공유 |
| **직원 (팀원)** | 팀원용 평가지의 하늘색 칸 작성 (부서·성명·본인평가·업적 기술) 후 제출 |
| **팀장** | ① 팀원 평가지에 **1차 평가** ② 본인은 팀장용 평가지를 작성해 제출 (피평가자) |
| **임원** | 팀원 평가지에 **2차 평가**, 팀장 평가지에 **평가 (1차만)** |
| **개별담당자** | 가점 항목별 **가점 기반 자료** 작성 (교육 이수, 상벌 등) |
| **대표이사** | 결과지 보고를 받고 **등급조정** 판단, 평가등급 확정 |
| **임원진** | 대표이사와 함께 등급조정 판단에 의견 반영 |

## 1-3. 오가는 것

| 오가는 것 | 모양 | 누가 → 누구 |
|---|---|---|
| **전사공지** | 평가 일정, 제출 기한, **가점 인정 기준일(11월 중순)** 안내 | 파트장 → 전 직원 |
| **팀원용 인사평가지** (빈 양식) | 엑셀 파일 | 파트장 → 팀원 |
| **팀장용 인사평가지** (빈 양식) | 엑셀 파일 | 파트장 → 팀장 |
| 작성된 평가지 | 엑셀 파일 | 직원·팀장 → 파트장 |
| 1차 평가 요청 평가지 묶음 | 부서별로 분류한 엑셀 | 파트장 → 팀장 |
| 2차 평가 요청 평가지 묶음 | 임원별로 분류한 엑셀 | 파트장 → 임원 |
| **가점 결과표** | 개인별 가점 기반 자료 | 개별담당자 → 파트장 |
| **결과지** (최종평가 취합표) | 그룹별 점수·등급 | 파트장 → 대표이사 |
| 등급조정 의견 | 구두·보고 자리 | 대표이사·임원진 → 파트장 |
| **평가결과** (개인 평가지·가점 포함) | **서면** 평가지, 연봉계약서와 함께 | 파트장 → 개별 직원 |
| 확정 평가등급 | 연봉조정용 | 파트장 → 연봉조정 |

### 평가지 구성 (현재 엑셀 양식 기준)

| 구분 | 팀원용 | 팀장용 |
|---|---|---|
| 평가자 | 팀장 60% + 임원 40% | 임원 100% (1차만) |
| **역량 평가 (30%)** | 10개 항목 × 1~10점: 공통역량(인성) 책임감·팀워크·규율성·객관성 / 직무역량 일처리·지식·정보력·기여도 / 대인관계 소통·신뢰성 | 10개 항목 × 1~10점: 공통역량(인성) 책임감·팀워크·규율성·객관성 / 직무역량 지식·정보력·기여도 / 팀장역량 리더쉽·소통·계획 |
| **업적 평가 (70%)** | 직원이 "올해 개인역할 및 업적"과 "차년도 개선 및 발전"을 직접 작성하고, 평가자는 **1~10점 한 개**를 매김 | 동일 |
| 본인평가 | 역량 10개 항목에 본인 점수 기입 (최종 점수에는 반영되지 않음) | 동일 |
| **가점** | 자격증·포상·직무발명보상·교육참여도·징계사항(감점)·내부회계관리제도 | 여기에 **다면평가** 추가 |

**평가 점수 계산 (양식 수식 기준)**
- 역량 점수 = 10개 항목의 (팀장 점수 × 60% + 임원 점수 × 40%) 합계 → 100점 만점 (팀장용은 임원 점수 합계)
- 업적 점수 = (팀장 점수 × 60% + 임원 점수 × 40%) × 10 → 100점 만점 (팀장용은 임원 점수 × 10)
- **평가 점수 = 역량 점수 × 30% + 업적 점수 × 70% + 가점**

**가점 기준 (양식 기재 내용)**
| 항목 | 기준 |
|---|---|
| 자격증 | 업무관련 자격증 취득(평가년도 취득분) 최대 2점 |
| 포상 | 공로상 2점, 우수상/혁신상 1.5점, 모범상/제안상 1점 |
| 직무발명보상 | 발명등록완료 시 특허 2점, 실용신안 등 1점 |
| 교육참여도 | 교육시간에 따라 가점 부여 (시간별 점수: **(미정)**) |
| 징계사항 | 인사위원회 징계결정에 따른 감점 (감점 폭: **(미정)**) |
| 내부회계관리제도 | 내부회계관리제도 관련 인원 가점 (점수: **(미정)**) |
| 다면평가 (팀장만) | 팀장의 다면평가 반영 (개선율, 총점수 고려). **별도 평가절차**가 있고, 그 결과를 입력함. 대상은 **팀장만**이라 전사에 반영되지 않음 |

## 1-4. 순서 (지금 방식)

1. **[11월 초] 전사공지** — 파트장이 전사공지로 **팀원용·팀장용 빈 양식**을 배포하고, 제출 기한과 **가점 인정 기준일(11월 중순 특정 시점)**을 알린다.
2. **평가지 작성·제출** — 직원(팀원·팀장)이 하늘색 칸(부서·성명·본인평가·업적 기술)을 채워 제출한다.
3. **전사 평가지 취합** — 파트장이 약 120명분 평가지를 모은다. 미제출자에게 **독촉**한다.
4. **부서별 분류 → 1차 평가 요청** — 파트장이 팀원 평가지를 부서별로 분류해 각 팀장에게 배포한다.
5. **1차 평가** — 팀장이 팀원 평가지에 항목별 점수를 매겨 돌려준다. 미제출 팀장에게 **독촉**한다.
6. **팀장별 취합 → 임원별 분류 → 2차 평가 요청** — 파트장이 1차 평가를 팀장별로 취합하고, 상위 임원 기준으로 다시 분류해 배포한다. 팀장용 평가지도 임원에게 배포한다.
7. **2차 평가** — 임원이 팀원 평가지에 2차 평가, 팀장 평가지에 평가(1차만)를 한다.
8. **[11월 중순 ~ 최종평가 전] 가점 반영** — 개별담당자가 가점 기반 자료를 작성해 넘기면, 파트장이 **개인 평가지마다 가점을 하나씩 입력**한다. (직원이 가점에 민감하므로, 나중에 피드백하려고 개인 평가지에도 넣는다.) 가점은 2차 평가 완료 여부와 관계없이 **최종평가 전**에만 들어가면 된다.
9. **최종평가 취합** — 파트장이 개인별 평가 점수를 결과지 한 장으로 취합한다.
10. **그룹별 상대평가** — 직급 그룹별로 점수 순으로 줄 세워 등급을 매긴다.
    - 그룹: **1그룹 팀장 / 2그룹 부장 / 3그룹 차장 / 4그룹 과장 / 5그룹 대리이하**
    - 비율(상위부터): **S 5% · A 20% · B 60% · C 15% · D 5%**
11. **대표이사 보고 → 등급조정** — 결과지를 대표이사에게 보고하고, 대표이사·임원진의 판단을 추가로 반영한다(1·2차 평가자의 왜곡 보정 포함). 누군가를 A로 올리면 **A 최하단 인원이 B로 밀려나는** 식으로, 그룹 내 비율을 지키며 등급 간 연쇄 변동이 생긴다.
12. **평가등급 확정 → 엑셀 재반영·재검토** — 조정된 등급을 엑셀 수식에 오류 없이 반영하고 다시 검토한다.
13. **연봉조정 반영** — 평가등급에 따라 연봉인상 차이가 있으므로 확정 등급을 연봉조정에 반영한다. (연봉조정을 평가등급 조정을 통해 반영하기도 한다.)
14. **평가결과 오픈** — 연봉계약서와 함께 개별 직원에게 평가결과(피드백)를 공유한다. 이의제기는 대부분 이 **면담 자리**에서 나온다.

## 1-5. 예외

| 상황 | 지금 처리 방식 |
|---|---|
| 7월 이후 입사자 | 평가 대상에서 제외 (6월 말까지 입사자만 대상) |
| 부서이동자 | **평가 진행 시점의 부서** 기준으로, 그 부서의 팀장·임원이 입력함. 이전 부서 기간이 긴 경우 부서장 간 **상호협의**는 **별도 단계**로 진행 |
| 팀장 공석 | 현재 없음 |
| 미제출 (직원·팀장·임원 누구든) | 파트장이 독촉. **한 명이라도 늦으면 다음 일정 전체가 밀린다.** |
| 업적 기술 부실 | 평가지를 되돌려 보내는 경우는 드묾. 잘 쓰는 사람과 못 쓰는 사람의 편차는 있음 |
| 등급조정 | 대표이사·임원진 판단으로 등급 변경 → 그룹 내 비율 유지를 위해 경계선 인원이 연쇄로 밀림. 최종점수는 조정된 사람을 포함해 **수정하지 않음**. 다만 **등급**과 **상위 %** 표시는 하향된 경우 해당 등급 **최상위 득점자**, 상향된 경우 해당 등급 **최하위 득점자**의 결과를 따라감 |
| 이의제기 | 있지만 드묾. **메일이나 구두**로 진행. 주로 연봉계약 면담 중에 얘기함 |
| 그룹 인원이 적어 비율이 1명 미만이 되는 경우 | 등급별 인원은 **반올림**으로 정함 |
| 동점자 | **근속 기준**으로 후순위자(근속이 짧은 사람)를 다음 등급으로 내림 |

## 1-6. 완료 조건

- 모든 대상자의 **평가등급이 확정**되고,
- 확정 등급이 **연봉조정에 반영**되고,
- 개별 직원에게 **평가결과가 공유**된 상태.

---

## 1-7. 바뀐 뒤의 모습 (TO-BE)

1. **[11월 초] 평가 시작 — 파트장**: 6월 말 기준 대상자 명단 확인, **직급 그룹** 및 **1차·2차 평가자** 지정(부서이동자는 평가 진행 시점 부서의 팀장·임원), 일정·가점 인정 기준일 입력 → 전 직원에게 **이메일 안내**.
2. **[개인작성 기간] 직원**: 시스템에서 본인평가·업적 작성 후 제출. 제출(완료) 시점부터 **1차 팀장과 2차 임원이 모두** 그 평가지를 볼 수 있음. 기간 안에서는 제출 후에도 고칠 수 있고, 쓰는 내용은 임시저장됨.
3. **[1차평가 기간] 1차 평가 — 팀장**: 팀원 평가 입력·제출. 기간 안에서는 고칠 수 있음. 팀장은 **2차 임원의 평가를 볼 수 없음**.
4. **[2차평가 기간] 2차 평가 — 임원**: 1차평가 기간에는 **보기만** 가능. **2차평가 기간**에 1차 평가지를 보면서 팀원 2차 평가를 입력 + **팀장 평가**(같은 2차평가 기간).
5. **진행 관리 — 관리자 (기간 내내)**: 관리자(현재 파트장·경영지원실장 2명, **추가 설정 가능**)는 **모든 과정을 모니터링**함. 현황판에서 **누가 어느 단계에서 멈췄는지** 확인 → 독촉 이메일 발송. 기간이 끝나면 관리자가 **다음 단계로 넘기기** → 앞 단계는 잠김. 기간이 지나도 저절로 잠기지 않고 "기한 지남"으로만 표시됨. 미제출자가 있으면 명단을 확인한 뒤 넘기고, 미제출자는 빈칸인 채로 잠김.
6. **[11월 중순 ~ 최종평가 전] 가점 반영 — 파트장**: 시스템은 가점 산정 규칙을 계산하지 않음. 개별담당자 자료로 산정된 가점을 **개인별로 별도 입력**하거나, **가점 항목별 칸이 있는 엑셀 템플릿으로 일괄 업로드** → 개인별 평가지에 항목별로 반영.
7. **최종평가**: 모든 평가·가점이 들어오면 **최종 점수와 그룹별 S~D 초안이 자동 산출**. 등급별 인원은 **반올림**, 동점자는 **근속 기준 후순위자를 다음 등급으로**.
8. **대표이사 보고·등급조정**: 대표이사가 **시스템에서 결과를 직접 확인**. 조정 입력은 **파트장**이 하고(최종점수는 그대로, **등급만** 수정), **밀려나는 인원이 즉시 표시**됨 → 확인 후 **확정**.
9. **연봉조정 연계**: 확정 등급(최종결과)을 **엑셀로 내려받아** 연봉조정에 사용.
10. **결과 피드백**: 연봉계약 면담 시점에 맞춰 파트장이 발송 시점을 정해 개인별로 **1차 점수, 2차 점수, 가점, 최종점수, 평가등급, 상위 %**를 이메일로 발송 → 끝. 최종점수는 실제 점수 그대로이고, 등급조정된 사람의 **등급·상위 %**는 하향 시 해당 등급 **최상위 득점자**, 상향 시 **최하위 득점자**의 결과를 따라감.
