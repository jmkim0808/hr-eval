# 5. 화면 검토 기준

> 기능을 만든 뒤 "이 화면에서 이 순서대로 일이 끝나는가"를 확인하는 문장이다.
> 각 문장은 **예 / 아니오**로 답할 수 있어야 한다. 하나라도 "아니오"면 그 흐름은 아직 끝나지 않은 것이다.

---

## 전체 흐름 (처음부터 끝까지)

- [ ] 파트장이 **엑셀 파일을 한 번도 열지 않고** 평가 시작부터 평가등급 확정까지 갈 수 있는가?
- [ ] 평가 시작 → 직원 작성 → 1차 평가 → 2차 평가 → 가점 반영 → 최종평가 → 등급조정 → 확정 → 엑셀 내려받기 → 이메일 발송이 **끊김 없이** 이어지는가?
- [ ] 화면에 쓰인 말이 용어집과 같은가? ("1차 평가", "2차 평가", "가점", "등급조정", "평가결과" 등을 다른 말로 바꾸지 않았는가?)

## 평가 시작 (파트장)

- [ ] 6월 말까지 입사한 사람만 평가 대상으로 나오는가?
- [ ] 대상자마다 그룹(1~5그룹), 평가지 종류(팀원용/팀장용), 1차·2차 평가자를 한 화면에서 확인하고 고칠 수 있는가?
- [ ] 부서이동자의 평가자를 최종 부서장으로 지정할 수 있는가?
- [ ] 제출 기한과 가점 인정 기준일을 입력하고, 전 직원에게 안내 이메일을 보낼 수 있는가?

## 평가지 작성 (직원)

- [ ] 직원이 안내 이메일을 받고 **자기 평가지로 바로 들어가** 작성할 수 있는가?
- [ ] 팀원에게는 팀원용 항목, 팀장에게는 팀장용 항목(팀장역량 포함)이 나오는가?
- [ ] 직원이 채울 칸(본인평가·업적 기술)과 평가자가 채울 칸이 구분되어, 직원이 평가자 점수 칸을 건드릴 수 없는가?
- [ ] 제출하면 파트장이 아무것도 하지 않아도 1차 평가자에게 넘어가는가?
- [ ] 제출(완료) 즉시 1차 팀장과 2차 임원이 **모두** 그 평가지를 볼 수 있는가?

## 1차·2차 평가 (팀장·임원)

- [ ] 팀장이 **자기 팀원 평가지만** 모아서 보는가?
- [ ] 역량 10개 항목과 업적 점수를 1~10점으로 매기고, 피평가자의 업적 기술을 보면서 평가할 수 있는가?
- [ ] 팀장이 제출하면 파트장이 분류하지 않아도 해당 임원에게 넘어가는가?
- [ ] 팀장 화면 어디에서도 **2차 임원의 평가 점수가 보이지 않는가?**
- [ ] 임원이 2차 평가할 때 **1차 평가지(팀장 점수)를 함께** 볼 수 있는가?
- [ ] 임원이 2차 평가할 팀원과 평가할 팀장을 **한곳에서** 구분해 볼 수 있는가?

## 진행 관리 (파트장)

- [ ] 파트장이 한 화면에서 **누가 어느 단계에서 멈췄는지** 알 수 있는가?
- [ ] 관리자가 작성부터 결과 발송까지 **모든 과정과 모든 평가지·점수**를 볼 수 있는가?
- [ ] 미제출자만 골라 **한 번에** 독촉 이메일을 보낼 수 있는가?
- [ ] 한 명 때문에 일정이 밀릴 때, 그 한 명이 누구인지 3초 안에 찾을 수 있는가?

## 가점 반영 (파트장)

- [ ] 가점 엑셀 템플릿을 **내려받고,** 채워서 **한 번 올리면** 전원에게 반영되는가?
- [ ] 템플릿 없이 **한 사람씩 가점을 별도 입력**할 수도 있는가?
- [ ] 시스템이 가점 산정 규칙을 계산하지 않고, 입력된 점수를 그대로 반영하는가?
- [ ] 2차 평가가 끝나지 않았어도 최종평가 전이면 가점을 올릴 수 있는가?
- [ ] 개인 평가지에 **항목별 가점 내역**(자격증·포상·직무발명보상·교육참여도·징계사항·내부회계관리제도, 팀장은 다면평가)이 보이는가?
- [ ] 가점표에서 이름이 맞지 않거나 빠진 사람이 있으면 알려 주는가?

## 최종평가 (파트장)

- [ ] 모든 평가와 가점이 들어오면 평가 점수가 **자동으로** 계산되는가? (역량 30% + 업적 70% + 가점, 팀원은 팀장 60%·임원 40%)
- [ ] 그룹별로 점수 순서가 보이고 S 5% · A 20% · B 60% · C 15% · D 5% 초안 등급이 나오는가?
- [ ] 등급별 인원이 **반올림**으로 계산되는가?
- [ ] 동점자가 등급 경계에 걸리면 **근속이 짧은 사람**이 다음 등급으로 내려가는가?
- [ ] 아직 평가가 끝나지 않은 사람이 있으면 최종평가를 돌리기 전에 알려 주는가?

## 대표이사 보고와 등급조정

- [ ] 대표이사가 시스템에 들어와 그룹별 결과를 **직접 볼 수 있고,** 수정은 할 수 없는가?
- [ ] 파트장이 한 사람의 등급을 바꾸면, 비율 때문에 **밀려나는 사람이 즉시** 보이는가?
- [ ] 조정 전 등급과 조정 후 등급을 나란히 확인할 수 있는가?
- [ ] 확정하면 등급이 더 이상 바뀌지 않는가?
- [ ] 확정 후 **수식 재검토 없이** 결과를 믿고 쓸 수 있는가? (조정 결과가 모든 화면과 내려받기 파일에 똑같이 반영되는가?)

## 결과 활용 (파트장)

- [ ] 확정된 최종결과를 **엑셀로 내려받을 수** 있는가?
- [ ] 파트장이 발송 시점을 정해 **개인별 평가결과를 이메일로** 보낼 수 있는가?
- [ ] 확정 전에는 결과 이메일이 나가지 않는가?
- [ ] 직원이 받은 결과에 **1차 점수, 2차 점수, 가점, 최종점수, 평가등급**이 모두 있는가?
- [ ] 등급조정으로 하향된 사람의 최종점수가 **해당 등급의 최상위** 수치로, 상향된 사람은 **최하단** 수치로 표시되는가?
- [ ] 직원 결과에 **원래 점수나 등급조정 여부**가 드러나지 않는가?

## 이 시스템이 하지 않아야 할 것 (경계 확인)

- [ ] 시스템이 평가자 대신 점수를 매기거나 추천하지 않는가?
- [ ] 시스템이 등급조정을 스스로 결정하지 않고, 파트장의 입력으로만 바뀌는가?
- [ ] 연봉 인상률 계산까지 들어가지 않고, 확정 등급 엑셀 제공에서 멈추는가?
