# 3. 불편함 목록

> 우선순위는 인터뷰에서 도메인 전문가가 직접 정한 순서다.

## 3-1. 해결할 것

| 순위 | 불편함 | 지금 벌어지는 일 | 바뀐 뒤 |
|---|---|---|---|
| **1** | **평가지 분류·재배포·취합** | 약 120명분 엑셀을 받아 부서별로 분류해 팀장에게, 다시 임원별로 분류해 임원에게 보낸다. 각 단계 결과를 일일이 모은다 | 제출하면 다음 평가자에게 자동으로 넘어가고, 취합이 따로 필요 없다 |
| **2** | **점수 계산·등급 재계산·수식 재검토** | 결과를 엑셀 수식에 오류 없이 반영해야 해서 재검토 시간이 오래 걸린다. 등급조정으로 누군가를 올리면 경계선 인원이 연쇄로 밀리는 것까지 다시 맞춰야 한다 | 평가 점수·그룹별 상대평가 등급이 자동 산출되고, 등급조정 시 밀려나는 인원이 즉시 표시된다 |
| **3** | **미제출자 독촉** | 직원·팀장·임원 중 한 명이라도 안 내면 다음 일정 전체가 밀린다. 누가 안 냈는지 확인하고 연락해야 한다 | 단계별 제출 현황을 한눈에 보고 독촉 이메일을 보낸다 |
| **4** | **가점을 개인 평가지에 하나씩 입력** | 개별담당자가 만든 가점 결과표를 보고 120명 평가지에 하나씩 옮겨 적는다 | 가점표를 한 번에 올리면 개인별로 반영된다 |
| **5** | **평가결과 개별 전달** | 연봉계약서와 함께 개인별로 평가결과를 전달한다 | 파트장이 정한 시점에 개인별 평가결과(가점 내역 포함)를 이메일로 발송한다 |
| **6** | **대표이사 보고 자료 준비** | 결과지를 별도로 만들어 보고한다 | 대표이사가 시스템에서 결과를 직접 본다 |
| **7** | **연봉조정용 결과 정리** | 확정 등급을 연봉조정에 다시 옮긴다 | 최종결과를 엑셀로 내려받는다 |

## 3-2. 해결하지 않을 것 (사람이 계속 판단)

| 불편함 / 일 | 해결하지 않는 이유 |
|---|---|
| 팀장·임원의 **점수 매기기** | 평가 판단은 평가자의 몫 |
| **가점 기반 자료 작성** (교육 이수, 상벌 등) | 개별담당자가 따로 작성한다. 시스템은 결과표를 받는 데서 시작 |
| 부서이동자 평가의 **상호협의** | 부서장 간 협의로 결정 |
| 대표이사·임원진의 **등급조정 판단** | 경영진의 판단. 시스템은 결과를 보여 주고, 입력은 파트장이 한다 |
| **연봉 인상률 결정·연봉 계산** | 이번 범위는 확정 등급 엑셀 제공까지 |
| **연봉계약 면담**과 **이의제기** 대응 | 사람 간 면담으로 처리 |
| **업적 기술 편차** (잘 쓰는 사람 / 못 쓰는 사람) | 이번 범위에서 다루지 않음 |
| 중국(심양)·베트남(빈푹) 법인 평가 | 이번 범위는 서울 본사 단독 |

## 3-3. 아직 정하지 않은 것 (미정)

| 항목 | 확인이 필요한 이유 |
|---|---|
| 그룹 인원이 적어 비율이 1명 미만일 때의 인원 산정 규칙 (반올림·올림·내림) | 자동 등급 산출의 전제 |
| 동점자 처리 기준 | 경계선 등급 결정의 전제 |
| 교육참여도·내부회계관리제도 가점 점수, 징계 감점 폭 | 가점표 업로드 양식을 정하는 데 필요 |
| 다면평가 진행 방법과 산정 방식 (개선율·총점수) | 팀장 가점 반영의 전제 |
| 부서이동자 상호협의 결과를 누가 어떻게 입력하는지 | 평가자 지정 기능의 전제 |
| 지금 평가지를 돌려받는 수단 (메일 회신 / 공유 폴더 등) | AS-IS 기록 보완용 (TO-BE에는 영향 적음) |
| 이의제기 공식 절차 상세 | 이번 범위 밖이지만 기록 필요 |

## 3-4. 참고 — 인터뷰 중 발견한 현재 양식 문제

- **팀장용 인사평가지의 가점 합계 수식(P4)에 다면평가 칸(D48)이 빠져 있다.** 지금 양식에서는 다면평가 점수를 적어도 평가 점수에 더해지지 않는다. 시스템을 만들 때 다면평가 가점을 합산에 넣을지 규정 기준으로 확인이 필요하다.
