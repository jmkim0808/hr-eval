# 인사평가 시스템 함께 시험하기 (팀원용)

새 인사평가 화면을 실제 운영 전에 써 보고 **불편한 점·이상한 점·좋은 점**을 알려 주시는 시험입니다. 이름·메일은 모두 **가짜**이고, 메일은 실제로 나가지 않습니다. 정답은 없으니 평소 쓰듯 눌러 보세요.

## 1. 들어가는 방법

1. 파트장이 보내 준 주소를 **크롬이나 엣지**에 넣습니다 (예: `http://192.168.0.15:3000/hr-eval/dev`). 사내망에서만 열립니다.
2. **시험용 포털** 화면에서 맡은 사람 이름 옆 **[이 사람으로 들어가기]** → 화면에 바로 보이는 인증번호 6자리를 넣습니다.
3. 다른 사람으로 바꿀 때는 화면 맨 위 **노란 줄 [사람 바꾸기 · 메일함]**. 같은 사람을 1분 안에 다시 고르면 "60초 뒤" 안내가 나옵니다 (실제와 같음).

## 2. 역할과 순서 (약 100분)

단계는 파트장(관리자 김인사)이 넘깁니다. **"다음 단계로 넘겼습니다"** 연락이 오면 다음 칸으로 갑니다.

| 단계 (시간) | 팀원 가 | 팀원 나 | 팀원 다 | 파트장 (김인사) |
|---|---|---|---|---|
| ① 본인평가 (25분) | **영업1팀 직원** 김대리·박과장·이주임·윤사원 평가지 쓰고 제출 | **품질·개발팀 직원** 강차장·서대리·임과장·조사원 평가지 제출 | **팀장** 최팀장·오팀장·장팀장 평가지(팀장용) 제출 | 진행 현황·독촉, 한 명은 [대신 입력] |
| ② 1차 평가 (25분) | **오팀장·장팀장**으로 팀원 평가 (각 2명) | **최팀장**으로 팀원 4명 평가 | **김대리·서대리**로 [내 가점 확인] → [정정 요청 보내기] | 가점 입력, 정정 요청 답변 |
| ③ 2차 평가 (25분) | **한전무**로 품질·개발팀 4명 + 팀장 2명 평가 | **최팀장**으로 들어가 2차 점수·의견이 **안 보이는지** 확인 | **정임원**으로 영업1팀 4명 + 최팀장 평가 | 진행 현황 |
| ④ 최종·결과 (15분) | 맡았던 직원으로 **[내 평가결과]** 확인 | 맡았던 직원으로 [내 평가결과], **[지난 평가 기록]** | **박대표**로 [등급 결과]에서 등급 바꿔 보기 | 관리자 조정 → 확정 → 결과 발송 → 마감 |
| ⑤ 의견 쓰기 (10분) | 의견 양식 작성 | 의견 양식 작성 | 의견 양식 작성 | 취합 |

## 3. 꼭 해 볼 것

| 화면 | 해 볼 것 |
|---|---|
| 내 평가지 | 위쪽 **보기 방식 [한 장씩] / [한눈에 보기]** 둘 다 써 보기. 제출 → **[제출 취소]** → 고쳐서 다시 제출 |
| 평가하기 (팀장·임원) | 점수 단추·숫자 키보드(1~0)·0.1점 −/+ 써 보기. 위쪽 **평균 게이지** 보면서 평균 80점(79.8~80.2)에 맞추기. 일부러 벗어나게 해서 막히는지·안내가 이해되는지 |
| 평가하기 | 제출 후 **[다음 사람 평가하기]**, [내 평가 현황]의 제출 일시·[이어서 평가하기] |
| 내 가점 / 결과 | 내 가점이 보이는지, 결과지에 등급·점수·가점·1·2차 평가의견이 보이는지 |
| 대표이사 | 등급을 S~D로 바꾸면 위쪽 분포 그림이 바로 바뀌는지 |
| 휴대폰 | 브라우저 창을 좁게 줄이거나 휴대폰으로 같은 주소 열어 보기 (사내 와이파이) |

## 4. 의견 남기는 법

**`팀-시험-의견양식.xlsx`** 에 한 줄씩 적어 주세요. 가장 도움이 되는 의견은 이렇게 생겼습니다.

> **누구로** 최팀장 / **어느 화면** 평가하기 / **무엇을 했을 때** 마지막 사람 제출 / **어땠나** 평균이 안 맞는다는데 어느 사람 점수를 고쳐야 할지 헷갈림

- 이상한 화면은 **캡처**(Windows: `Win + Shift + S`)해서 파일 이름을 양식에 적어 주세요.
- 평가 제도(평균 80점, 가점 기준 등)에 대한 의견도 환영합니다 — 양식의 "구분"에서 **제도**를 고르세요.

## 5. 주의

- 시험 데이터는 언제든 지워질 수 있습니다. 실제 내 평가 내용·실제 동료 이름을 넣지 마세요.
- 화면이 "잠시 이용할 수 없습니다"가 나오면 파트장에게 알려 주세요 (보안 열쇠 잠김).
- 접속이 안 되면: 파트장 PC가 켜져 있는지, 같은 사내망(유선·사내 와이파이)인지 확인해 주세요.
