# 내 PC에서 시험해 보기 (시험 모드)

사내 포털 없이 내 PC에서 인사평가 전체 흐름을 해 볼 수 있습니다. **가짜 명단만** 씁니다. 메일은 실제로 나가지 않고 화면의 "보낸 메일함"에만 남습니다.

## 1. 처음 한 번 설치 (20~30분)

| 순서 | 할 일 | 참고 |
|---|---|---|
| 1 | **Node.js** 설치 | https://nodejs.org → "LTS" 버튼 → 받은 파일 실행 → 계속 [Next] |
| 2 | **PostgreSQL 16** 설치 | https://www.postgresql.org/download/windows → "Download the installer" → 16.x Windows 받기 → 실행. 중간에 **비밀번호**를 정하라고 나오면 정하고 메모(나중에 1번 물어봄). 포트는 5432 그대로. 마지막 "Stack Builder"는 체크 해제 |
| 3 | **프로그램 받기** | https://github.com/jmkim0808/hr-eval → 위쪽 브랜치 선택에서 `claude/fervent-bardeen-te2f5r` → 초록 [Code] → [Download ZIP] → 압축 풀기 (바탕화면 등 한글 없는 경로 권장, 예: `C:\hr-eval`) |
| 4 | **`시험-설치.bat`** 더블클릭 | 검은 창에서 PostgreSQL 사용자 이름은 Enter, 비밀번호는 2번에서 정한 것 입력. "✔ 준비 끝"이 나오면 창 닫기 |

> Windows가 "PC를 보호했습니다"라고 하면 [추가 정보] → [실행]. 회사 PC 보안 프로그램이 막으면 전산 담당자에게 Node.js·PostgreSQL 설치 허용을 요청하세요.

## 2. 켜기 · 끄기

- 켜기: **`시험-켜기.bat`** 더블클릭 → 브라우저에 **시험용 포털**이 열립니다 (안 열리면 `http://127.0.0.1:3000/hr-eval/dev` 직접 입력)
- 끄기: 검은 창을 닫습니다
- 처음부터 다시: 끈 상태에서 **`시험-초기화.bat`** → `y` (명단·점수·보안 열쇠가 모두 지워짐)

## 3. 시험 순서 (추천)

화면 맨 위 **노란 줄 [사람 바꾸기 · 메일함]**으로 언제든 다른 사람으로 바꿉니다. 인증번호는 화면에 바로 보입니다. 같은 사람을 1분 안에 다시 고르면 "60초 뒤" 안내가 나옵니다 (실제와 같음).

| # | 누구로 | 해 볼 것 |
|---|---|---|
| 1 | 김인사(관리자) | 처음 들어오면 **보안 열쇠 만들기** → 비밀 문구(12자 이상) 정하기 → 이관리 열쇠 칸 추가 |
| 2 | 김인사 | [평가 시작 설정] → [템플릿 올리기]로 **`시험자료\시험용-명단.xlsx`** 올리기 → 반영 → 기간 저장 → [안내 이메일 발송] → 노란 줄의 메일함에서 안내 메일 확인 |
| 3 | 김대리 등 직원 | 내 평가지 작성·임시저장·제출, 다른 사람 평가지는 안 보이는지 |
| 4 | 김인사 | [진행 현황]에서 미제출자 보기·독촉 → [다음 단계로 넘기기] (1차평가) |
| 5 | 최팀장 | 팀원 4명 1차 평가. **평균 80점** 규칙: 마지막 사람 제출 때 평균이 79.5~80.5를 벗어나면 막히고 고칠 방법이 나옴 |
| 6 | 김인사 → 정임원·한전무 | 2차평가로 넘기기 → 임원이 2차 평가·팀장 평가 (최팀장 화면에는 2차 점수가 안 보이는지) |
| 7 | 김인사 | 최종평가로 넘기기 → 가점(템플릿) → 최종평가 표·등급조정 → 확정 |
| 8 | 박대표(대표이사) | 등급 결과 표만 보이고 업적 글·항목 점수는 안 보이는지 |
| 9 | 김인사 → 직원 | 결과 발송 → 직원이 내 평가결과 확인(조정 여부는 안 보임) → 평가 마감 |
| 10 | 보안 열쇠 | [보안 열쇠] → [지금 잠그기] → 직원 화면이 "잠시 이용할 수 없습니다"로 바뀌는지 → 비밀 문구로 다시 열기 |

이상한 점은 **어느 사람으로, 어느 화면에서, 무엇을 눌렀을 때** 생겼는지 화면 캡처와 함께 알려 주세요.

## 4. 알아 둘 것

- 시험 모드는 `.env.local`의 `HR_DEMO=on`일 때만 켜집니다. 실제 사내 서버에는 이 값을 넣지 않으며, 넣어도 메일을 실제로 보내는 설정(`MAIL_MODE=smtp`)에서는 꺼집니다.
- 실제 직원 이름·메일을 시험 모드에 넣지 마세요 (개인정보 보호).
- 검은 창을 닫았다가 다시 켜면 보안 열쇠가 잠깁니다 → 관리자로 들어가 비밀 문구로 여세요 (실제 운영과 같은 동작).
