# 내 PC에서 시험해 보기 (시험 모드)

사내 포털 없이 내 PC에서 인사평가 전체 흐름을 해 볼 수 있습니다. **가짜 명단만** 씁니다. 메일은 실제로 나가지 않고 화면의 "보낸 메일함"에만 남습니다.

## 1. 처음 한 번 설치 (20~30분)

| 순서 | 할 일 | 참고 |
|---|---|---|
| 1 | **Node.js** 설치 | https://nodejs.org → "LTS" 버튼 → 받은 파일 실행 → 계속 [Next] |
| 2 | **PostgreSQL 16** 설치 | https://www.postgresql.org/download/windows → "Download the installer" → 16.x Windows 받기 → 실행. 중간에 **비밀번호**를 정하라고 나오면 정하고 메모(나중에 1번 물어봄). 포트는 5432 그대로. 마지막 "Stack Builder"는 체크 해제 |
| 3 | **프로그램 받기** | https://github.com/jmkim0808/hr-eval → 위쪽 브랜치 선택에서 `claude/fervent-bardeen-te2f5r` → 초록 [Code] → [Download ZIP] → 압축 풀기 (바탕화면 등 한글 없는 경로 권장, 예: `C:\hr-eval`) |
| 4 | **`시험-설치.bat`** 더블클릭 | 검은 창에서 PostgreSQL 사용자 이름은 Enter, 비밀번호는 2번에서 정한 것 입력. "✔ 준비 끝"이 나오면 창 닫기 |

> Windows가 "PC를 보호했습니다"라고 하면 [추가 정보] → [실행]. 회사 PC 보안 프로그램이 막으면 전산 담당자에게 Node.js·PostgreSQL 설치 허용을 요청하세요.

### 이미 예전 버전을 설치했다면 (업데이트, 10~15분)

1. 켜 둔 검은 창이 있으면 닫습니다.
2. 위 3번처럼 **새 ZIP을 받아 새 폴더에** 압축을 풉니다 (예: `C:\hr-eval-1016`). 예전 폴더는 지워도 됩니다.
3. 새 폴더에서 **`시험-설치.bat`** → PostgreSQL 사용자 이름은 Enter, 비밀번호 입력 → "✔ 준비 끝"
4. 이어서 **`시험-초기화.bat`** → `y` (예전 시험 데이터를 지우고 새 버전 상태로 시작)
5. **`시험-켜기.bat`**

## 2. 켜기 · 끄기

- 켜기: **`시험-켜기.bat`** 더블클릭 → 브라우저에 **시험용 포털**이 열립니다 (안 열리면 `http://127.0.0.1:3000/hr-eval/dev` 직접 입력)
- 끄기: 검은 창을 닫습니다
- 처음부터 다시: 끈 상태에서 **`시험-초기화.bat`** → `y` (명단·점수·보안 열쇠가 모두 지워짐)

## 3. 시험 순서 (추천)

화면 맨 위 **노란 줄 [사람 바꾸기 · 메일함]**으로 언제든 다른 사람으로 바꿉니다. 인증번호는 화면에 바로 보입니다. 같은 사람을 1분 안에 다시 고르면 "60초 뒤" 안내가 나옵니다 (실제와 같음). 두 사람을 동시에 보려면 브라우저를 하나 더 씁니다(엣지 + 크롬).

| # | 누구로 | 해 볼 것 | 이번에 새로 볼 곳 |
|---|---|---|---|
| 1 | 김인사(관리자) | 처음 들어오면 **보안 열쇠 만들기** → 비밀 문구(12자 이상) → 이관리 열쇠 칸 추가 | 왼쪽 세로 메뉴, 새 화면 디자인 |
| 2 | 김인사 | [평가 시작 설정] → [템플릿 올리기]로 **`시험자료\시험용-명단.xlsx`** → 반영 → 기간 저장 → [안내 이메일 발송] → 노란 줄 메일함에서 안내 메일 확인 | 기간을 바꾸면 [변경 안내 메일 보내기] |
| 3 | 김대리 등 직원 | 내 평가지 작성·제출 — 기본은 **한 장씩**(점수를 누르거나 숫자키 1~0을 누르면 다음 항목), 왼쪽 **전체 흐름**에서 아무 항목이나 눌러 이동, 오른쪽 위 **[한눈에 보기]**로 바꿔 보기, 마지막 장에서 제출 | 새 화면. 휴대폰 화면(브라우저 창을 좁혀 보기) |
| 4 | 김인사 | [진행 현황] 숫자 카드·**부서별 진행 막대**·미제출자·독촉 → [다음 단계로 넘기기] (1차평가). 1차 점수가 들어오면 **역량×업적 9칸 표**가 나타남 | 출장자 대신: 미제출자 이름 → [대신 입력] |
| 5 | 김인사 | **[가점 입력]**에서 김대리 줄을 눌러 가점 넣기 → 다시 고쳐 보기 | |
| 6 | 김대리 | 내 할 일 → **[내 가점 확인]**: 넣자마자 보이는지, "바뀐 기록"(1 → 0.5 등), **[정정 요청 보내기]** | 새 기능 |
| 7 | 김인사 | [가점 입력] 아래 **직원 정정 요청** → 답변 쓰고 [처리 완료] → 김대리 화면에 "처리 완료"·답변 | 새 기능 |
| 8 | 최팀장 | 팀원 1차 평가 — 위쪽 **맡은 사람 띠**·**평균 게이지**, 한 장씩 카드에서 점수 단추(주황 밑줄 = 본인평가 점수)·**0.1점 −/+**, `Enter`로 다음, 오른쪽 **본인 업적·가점**, **평가의견** 장 → 제출하면 다음 사람으로 | 새 화면 |
| 9 | 최팀장 | 마지막 사람 제출 때 평균이 79.5~80.5를 벗어나면 막히고 몇 점을 고치면 되는지 나옴 → [내 평가 현황]에서 **숫자 카드·내가 준 점수 분포 그림**·팀원 표 | 그림 새로 |
| 10 | 김인사 → 정임원·한전무 | 2차평가로 넘기기 → 임원이 2차 평가(1차 의견이 보임)·팀장 평가. **최팀장 화면에는 2차 점수·2차 의견이 안 보이는지** | |
| 11 | 김인사 | 최종평가로 넘기기 → [최종평가]: 관리자 조정(비중 유지, 한 명 올리면 한 명 밀려남) → 옆 칸 **[대표이사 조정 · 최종]**에 대신 넣어 보기 ("관리자 대신 입력"으로 표시) | 새 기능 |
| 12 | 박대표(대표이사) | [등급 결과] 위쪽 **등급 분포 · 기준 대비 그림** 확인 → 사람마다 **S~D를 직접 골라 보기** — 그림이 바로 바뀌고 다른 사람은 안 움직임, "조정 없음"을 고르면 되돌아감 | 새 기능 |
| 13 | 김인사 | 확정 → [결과 발송] → 평가 마감 (실수로 넘겼으면 [이전 단계로 되돌리기]) | |
| 14 | 김대리 | [내 평가결과]: 등급(대표이사 조정 반영)·점수·가점·**1차·2차 평가의견**, 조정 여부는 안 보임 | 평가의견 새로 |
| 15 | 아무나 → 시험용 포털 | 노란 줄 [사람 바꾸기] 화면 아래 **[작년 평가 기록 만들기]** (관리자가 보안 열쇠를 연 뒤) | 시험용 |
| 16 | 김대리 / 최팀장 / 정임원 | 내 할 일 → **[지난 평가 기록]**: 김대리는 자기 작년 평가지(업적 글)·결과, 최팀장은 그 해 평가한 팀원 기록(2차 점수·의견 없음), 정임원은 1·2차 모두 | 새 기능 |
| 17 | 김인사 | [평가 관리] → 새 정기평가 만들기 / 지난 평가 보기·엑셀 | |
| 18 | 보안 열쇠 | [보안 열쇠] → [지금 잠그기] → 직원 화면이 "잠시 이용할 수 없습니다" → 비밀 문구로 다시 열기 | |

이상한 점은 **어느 사람으로, 어느 화면에서, 무엇을 눌렀을 때** 생겼는지 화면 캡처와 함께 알려 주세요.

## 4. 알아 둘 것

- 시험 모드는 `.env.local`의 `HR_DEMO=on`일 때만 켜집니다. 실제 사내 서버에는 이 값을 넣지 않으며, 넣어도 메일을 실제로 보내는 설정(`MAIL_MODE=smtp`)에서는 꺼집니다.
- 실제 직원 이름·메일을 시험 모드에 넣지 마세요 (개인정보 보호).
- 검은 창을 닫았다가 다시 켜면 보안 열쇠가 잠깁니다 → 관리자로 들어가 비밀 문구로 여세요 (실제 운영과 같은 동작).
