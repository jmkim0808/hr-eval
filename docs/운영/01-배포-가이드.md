# 배포 가이드 — Cloudflare(무료) + Supabase(무료)

> 2026-10-02 처음 작성. 메뉴 이름은 각 회사 화면 개편에 따라 바뀔 수 있다(추정). 다르면 비슷한 이름을 찾는다.

**걸리는 시간** 30~40분 · **비용** 0원 (Cloudflare Workers 무료, Supabase 무료 — ADR-0002·0003·0011)
**준비물** 회사 이메일, 다우오피스 SMTP 정보, 관리자 2명·대표이사의 이름과 이메일

---

## 1. Supabase — 데이터 저장소 만들기 (10분)

1. https://supabase.com 에 **회사 이메일**로 가입한다 (개인 계정 X — 퇴사·인수인계 대비).
2. **New project**
   - Name: `hr-eval`
   - Database Password: [Generate]로 만든 긴 비밀번호 → **회사 비밀번호 관리 방식으로 보관** (다시 볼 수 없음)
   - Region: **Northeast Asia (Seoul)**
   - Plan: **Free**
3. 만들어지면 **Settings → API(또는 Data API) → Data API 끄기**.
   우리 서비스는 서버에서만 DB에 접속한다. 이걸 꺼야 인터넷에서 DB를 바로 읽는 길이 닫힌다 (ADR-0003).
4. 위쪽 **Connect** 버튼 → **Transaction pooler** 탭 → 주소(URI)를 복사한다.
   `postgresql://postgres.xxxx:[YOUR-PASSWORD]@aws-0-ap-northeast-2.pooler.supabase.com:6543/postgres`
   `[YOUR-PASSWORD]`를 2번의 비밀번호로 바꾼 것이 **PROD_DATABASE_URL** 이다. 채팅·메일로 보내지 않는다.

## 2. Cloudflare — 실행할 곳 준비 (10분)

1. https://dash.cloudflare.com 로그인 (회사 계정).
2. 왼쪽 **Workers & Pages** → 처음이면 workers.dev 하위 주소를 정하라고 한다 → `powernet` 등 입력.
   서비스 주소는 `https://hr-eval.<정한이름>.workers.dev`가 된다.
3. **Account ID**: Workers & Pages 개요 오른쪽(또는 계정 홈 오른쪽 아래)에 있다 → **CLOUDFLARE_ACCOUNT_ID**
4. **API 토큰**: 오른쪽 위 사람 모양 → **My Profile → API Tokens → Create Token**
   - 템플릿 **Edit Cloudflare Workers** 선택
   - Account Resources: **회사 계정만** / Zone Resources: **All zones from an account → 회사 계정** (도메인을 안 쓰면 영향 없음)
   - TTL(유효 기간): 배포 기간만 (예: 한 달). 끝나면 지운다.
   - 만든 값 → **CLOUDFLARE_API_TOKEN** (한 번만 보인다)

## 3. 다우오피스 SMTP (담당 업체·관리자 화면에서 확인)

| 값 | 예시 | 비고 |
|---|---|---|
| SMTP_HOST | (다우오피스 안내값) | |
| SMTP_PORT | 465 | 465(SSL) 또는 587(STARTTLS) |
| SMTP_USER / SMTP_PASS | 발송 전용 계정 | 개인 계정 대신 `hr-noreply@` 같은 발송 전용 계정 권장 |
| MAIL_FROM | `파워넷 인사평가 <hr-noreply@powernet.co.kr>` | SMTP_USER와 같은 주소 |

**확인할 것 (아직 확인 못 함)**: 외부 서버(Cloudflare)에서 SMTP 접속 허용 여부, 하루·시간당 발송 한도. 한 번에 약 120통을 1분에 10통씩 보낸다.

## 4. 배포 — 둘 중 하나

### 방법 A. Claude가 대신 (권장: 따라 할 것이 적다)

이 작업 환경(Claude Code 클라우드 환경)의 설정에서:
1. **네트워크**: 허용 도메인에 `api.cloudflare.com`, `*.supabase.com`, `aws-0-ap-northeast-2.pooler.supabase.com` 추가
2. **환경 변수**에 아래를 넣는다 (채팅창에 붙여 넣지 않는다)
   `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`, `PROD_DATABASE_URL`,
   `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `MAIL_FROM`,
   `ADMINS` = `김파트장:part@powernet.co.kr,이실장:director@powernet.co.kr`, `CEO` = `대표이사:ceo@powernet.co.kr`
3. 새 세션에서 "배포해줘" → Claude가 `scripts/deploy-cf.sh`를 실행한다.

※ DB 접속(6543 포트)은 이 환경의 프록시를 못 지날 수 있다(추정). 그러면 1단계(표 만들기)만 방법 B로 하거나 Claude가 다른 방법을 안내한다.

### 방법 B. 파트장 PC에서 직접

1. Node.js 22 LTS와 Git 설치 (Windows는 Git과 함께 오는 **Git Bash** 사용)
2. Git Bash에서:
   ```bash
   git clone https://github.com/jmkim0808/hr-eval.git && cd hr-eval
   git checkout claude/fervent-bardeen-te2f5r
   npm install
   export CLOUDFLARE_API_TOKEN=... CLOUDFLARE_ACCOUNT_ID=... PROD_DATABASE_URL='...'
   export SMTP_HOST=... SMTP_PORT=465 SMTP_USER=... SMTP_PASS='...' MAIL_FROM='파워넷 인사평가 <hr-noreply@powernet.co.kr>'
   export ADMINS='김파트장:part@powernet.co.kr,이실장:director@powernet.co.kr' CEO='대표이사:ceo@powernet.co.kr'
   ./scripts/deploy-cf.sh
   ```
3. 마지막 줄에 나온 주소가 서비스 주소다. 창을 닫으면 입력한 값은 사라진다.

**스크립트가 하는 일**: DB 표 만들기·잠금 → 관리자·대표이사 등록 → 메일 Worker 먼저 → 본 프로그램 빌드·배포 → 비밀값(DB 주소·서명 키·예약 실행 키·SMTP) 저장 → 메일 Worker 완성(1분마다 예약 실행). 비밀값은 화면에 찍지 않고 Cloudflare 비밀값에만 들어간다. SMTP 값이 없으면 멈춘다(운영에서 메일 내용을 기록에 남기지 않기 위해, ADR-0018).

## 5. 배포 뒤 확인 (10분)

- [ ] 주소를 열면 "이메일 인증" 화면이 나온다
- [ ] 관리자 이메일로 인증번호 메일이 1분 안에 온다 (스팸함도 확인)
- [ ] 인증하면 "진행 현황 — 아직 시작한 평가가 없습니다"가 보인다
- [ ] 대표이사 이메일로 들어가면 "등급 결과 — 아직 보고할 결과가 없습니다"만 보인다
- [ ] Cloudflare → Workers → hr-eval → Logs에 이름·이메일·인증번호가 찍혀 있지 않다
- [ ] Supabase → Table Editor에서 표 옆에 "RLS enabled"가 보인다

## 6. 보안 · 비용 · 유지보수

| 항목 | 내용 |
|---|---|
| 비용 | 0원. 무료 한도: Cloudflare 하루 10만 요청·요청당 CPU 10ms, Supabase 500MB·7일 미사용 시 멈춤(1분마다 깨우므로 해당 없음) |
| 서비스 크기 | 2.37MB / 무료 한도 3MB (79%) — 기능을 더 늘리면 유료(월 5달러, 추정) 검토 |
| 백업 | 무료 DB는 자동 백업 없음 → 단계를 넘길 때마다 화면 안내에 따라 **전체 기록 백업 엑셀**을 받아 사내 보안 저장소에 보관 (ADR-0011). 평가 시작 2주 전 유료 전환 여부 재결정 |
| 접근 | 서비스는 이메일 인증한 사람만. DB는 Data API 꺼짐 + 모든 표 잠금(RLS). Cloudflare·Supabase 계정은 2단계 인증 켜기 |
| 비밀값 | DB 주소·SMTP 비밀번호·API 토큰은 저장소·채팅·메일에 두지 않는다. 토큰은 배포 끝나면 삭제·재발급 |
| 유지보수 | 평상시 할 일 없음. 오류가 있으면 다음 날 아침 8시 요약 메일이 온다. 다시 배포는 4번을 다시 실행 |

## 7. 문제가 생기면

| 증상 | 확인 |
|---|---|
| 인증번호 메일이 안 옴 | SMTP 값·포트(465/587), 다우오피스 외부 SMTP 허용, 스팸함 |
| "문제가 생겼습니다 · 요청 번호" | 다음 날 요약 메일의 요청 번호와 맞춰 보고 Claude에게 요청 번호만 전달 |
| 배포 중 `Authentication error` | API 토큰 권한(Edit Cloudflare Workers)·계정 선택 |
| DB 접속 실패 | PROD_DATABASE_URL의 비밀번호 부분, 6543(Transaction pooler) 주소인지 |
