# 인터넷 시험 서버 올리기 (Render)

사내망 공유가 회사 보안 프로그램에 막혀, 팀 시험은 **인터넷의 임시 서버**에서 합니다. 팀원은 어디서든 주소 + **입구 비밀번호**로 들어옵니다. 실제 운영은 계속 사내 포털(`02-사내-포털-설치.md`)이고, 이 서버는 시험이 끝나면 지웁니다.

| 항목 | 내용 |
|---|---|
| 업체 | Render (미국 회사, 서버 위치 싱가포르) |
| 비용 | **0원** (무료 요금제). 안 잠들게 하려면 Starter 월 7달러 |
| 걸리는 시간 | 처음 20~30분 (가입 5분 + 자동 설치 10분 + 확인) |
| 비밀 값 | 서버 비밀 값은 Render가 직접 만듭니다. 파트장이 정하는 것은 **입구 비밀번호 1개**뿐 — 채팅·메일에 남기지 말고 메신저로 팀원에게만 |
| 데이터 | **가짜 명단만.** 실제 직원 이름·평가 내용 금지 |

## 1. 가입 (5분)

1. https://render.com → **[Get Started]** → **[GitHub]**로 가입합니다 (저장소가 GitHub에 있어서 가장 간단). 가능하면 회사 메일과 연결된 계정.
2. 카드 등록을 물어보면: 무료 요금제는 등록 없이 쓸 수 있는 경우가 많습니다(추정). 요구하면 등록해도 무료 요금제에서는 청구되지 않습니다.

## 2. 서버 만들기 (클릭 몇 번 + 자동 설치 10분)

1. Render 화면 위쪽 **[+ New] → [Blueprint]**
2. **Connect a repository** → GitHub 권한 창이 뜨면 **Only select repositories → `hr-eval`만** 고르고 [Install/Save]
3. 목록에서 `jmkim0808/hr-eval` 옆 **[Connect]**
4. **Branch**: `claude/fervent-bardeen-te2f5r` 로 바꿉니다 (중요 — 이 브랜치에 설정 파일 `render.yaml`이 있음)
5. Blueprint Name: `hr-eval-test`
6. 아래에 **`HR_DEMO_GATE`** 입력 칸이 나옵니다 → **팀원과 나눌 입구 비밀번호**를 정해 넣습니다
   - 10자 이상, 회사에서 쓰는 다른 비밀번호와 다르게 (예시 형식: 단어 2개 + 숫자)
7. **[Apply]** (또는 [Deploy Blueprint]) → 서버(`hr-eval-test`)와 DB(`hr-eval-test-db`)가 만들어지고 설치가 시작됩니다 (10분 안팎)
8. 서버 화면에서 **Live**(초록)가 되면 위쪽에 주소가 보입니다: `https://hr-eval-test.onrender.com` (이름이 겹치면 뒤에 글자가 붙음)

> 화면 이름·버튼 위치는 Render 화면 개편에 따라 조금 다를 수 있습니다(추정). 막히면 그 화면을 캡처해서 보내 주세요.

## 3. 들어가 보기

1. 주소 뒤에 **`/hr-eval/dev`** 를 붙여 엽니다 → 예: `https://hr-eval-test.onrender.com/hr-eval/dev`
2. 브라우저 **로그인 창**이 뜹니다 → 사용자 이름: 아무거나(예: `test`) / 비밀번호: 2-6번에서 정한 것
3. 시험용 포털이 열리면 성공. 이후는 PC 시험과 같습니다 (`03-PC-시험-안내.md` 3장).

PC 시험과 다른 점:

| 항목 | 인터넷 시험 서버 |
|---|---|
| 보안 열쇠 | **저절로 열려 있습니다** (시험 서버 전용 설정). 3장 1번 "보안 열쇠 만들기"는 건너뜁니다 |
| 시험용 명단 | 내 PC 시험 폴더의 **`시험자료\시험용-명단.xlsx`** 를 [평가 시작 설정]에서 올립니다 |
| 잠듦 | 15분 동안 아무도 안 쓰면 잠들고, 다음 접속 때 **1분쯤** 걸려 깹니다. 데이터는 그대로 |
| 처음부터 다시 | 4장 참고 |

## 4. 운영 중 할 일

| 할 일 | 방법 |
|---|---|
| 팀원에게 안내 | 주소(`…/hr-eval/dev`)와 입구 비밀번호를 **메신저로 따로** 보냅니다. 안내문·의견 양식 첨부 |
| 비밀번호 바꾸기 | 서버 화면 왼쪽 **Environment** → `HR_DEMO_GATE` 값 수정 → 저장하면 다시 켜짐 |
| 잠들지 않게 | 서버 화면 **Settings → Instance Type → Starter** (월 7달러, 시험 날만 쓰고 다시 Free로) |
| 처음 상태로 | DB 화면(`hr-eval-test-db`) **Settings → Delete Database** → Blueprint 화면에서 **[Sync]**(또는 [Manual sync]) → 새 DB로 다시 만들어짐 (추정 — 안 되면 알려 주세요. 시험용 포털에 [시험 데이터 지우기] 단추를 만들어 드릴 수 있음) |
| 코드 고친 것 반영 | 브랜치에 새 커밋이 올라가면 **저절로 다시 설치**됩니다 (5~10분, 그동안 접속이 잠시 끊길 수 있음) |

## 5. 끝나면 (꼭)

1. Blueprint `hr-eval-test` 화면 → **Settings → Delete Blueprint** (서버·DB 함께 지우기 선택). 또는 서버·DB를 각각 Settings → Delete
2. GitHub → Settings → Applications → Render 권한을 지워도 됩니다 (선택)

무료 DB는 만든 날부터 **30일 뒤 만료**되고, 14일 안에 올리지 않으면 지워집니다 — 지우는 것을 잊어도 데이터가 남지 않습니다.

## 6. 리스크

| 리스크 | 영향 | 대응 |
|---|---|---|
| 주소·비밀번호가 밖으로 퍼짐 | 외부인이 시험 화면(가짜 데이터)을 봄 | 가짜 명단만 쓰고, 비밀번호는 메신저로만. 의심되면 4장으로 비밀번호 변경. 검색엔진 노출 막음(noindex) |
| 실수로 실제 명단을 올림 | 개인정보 해외 서버 저장 | 시험용 명단 파일만 쓰기. 올렸으면 즉시 4장 "처음 상태로"(DB 삭제) |
| 시험 중 잠듦·재설치 | 1분 대기, 잠시 끊김 | 시험 날은 Starter로 올리거나, 시험 중에는 코드를 올리지 않음 |
| 시험 모드는 누구나 관리자·대표이사가 될 수 있음 | 팀원이 단계를 넘기거나 바꿈 | 역할표대로만. 실수로 넘기면 관리자 화면 [이전 단계로 되돌리기] |
